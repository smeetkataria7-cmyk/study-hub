Structure of a computer

Parts, stored programs, data representation, instructions and buses.
1.1

Functions of a computer

  • Data processing — arithmetic and logic on data.
  • Data storage — short-term (registers, memory) and long-term (disk).
  • Data movement — between the computer and the outside world (I/O) and between its own parts (communication).
  • Control — coordinates the other three.
1.2

Structure of a digital computer

Four main parts joined by the system interconnection (buses): CPU, main memory, I/O modules.

  • CPU = control unit + ALU + registers + CPU interconnection.
  • Control unit — fetches and decodes instructions and issues control signals.
  • ALU — performs arithmetic and logical operations.
  • Registers — fast storage inside the CPU.
1.3

Basic functional units

  • Input unit, output unit, memory (main and secondary), ALU, control unit.
  • The ALU and control unit together form the processor.
1.4

Stored-program concept (von Neumann)

Instructions and data are stored together in the same read-write memory, addressed by location and not by type. The CPU fetches instructions one after another using the program counter (sequential execution). This idea removes the need to rewire the machine to change the program.

1.5

IAS computer

  • Main memory: 1000 words of 40 bits each (addresses 0–999).
  • A word holds one number (sign + 39 bits) or two 20-bit instructions: 8-bit opcode + 12-bit address each.
  • Registers: MBR (memory buffer), MAR (memory address), IR (instruction register), IBR (instruction buffer, holds the right instruction), PC, AC (accumulator) and MQ (multiplier quotient).
  • Works in a repeated fetch (instruction into IR) and execute cycle; the right-hand instruction is taken from IBR without a memory access.

1.9

Instruction formats

An instruction has an opcode and zero or more operand fields. Formats by number of addresses:

  • 3-address: ADD R1, R2, R3 (R1 ← R2 + R3).
  • 2-address: ADD R1, R2 (R1 ← R1 + R2).
  • 1-address: ADD X (AC ← AC + M[X]), uses the accumulator.
  • 0-address: stack machines, ADD pops two and pushes the sum.
  • Opcode bits decide how many operations exist: 2opcode bits.

1.11

System buses

addressable memory  2nbandwidth  bus width × transfers per second
  • Data bus — carries data; its width sets how many bits move at once.
  • Address bus — carries the memory / I/O address; n lines address 2n locations.
  • Control bus — read / write, interrupt, clock, bus request / grant signals.
1.12

Bus interconnection and I/O mechanisms

Many devices share a bus, so arbitration decides who may use it (centralised or distributed). Single-bus designs are cheap but slow; multiple buses (local, system, expansion) reduce contention. I/O modules connect devices to the buses (detail in Module 5).

Theory questions and model answers

Tap "Show model answer" to reveal.
Q1

List the basic functions of a computer.

Show model answer
  • Data processing, data storage, data movement (I/O and internal communication) and control that coordinates them.
Q2

Explain the stored-program concept.

Show model answer

Instructions and data are kept together in the same read-write memory and addressed by location, not by type. The CPU fetches instructions sequentially using the program counter, so changing the program only means changing memory contents, not rewiring the machine.

Q3

Describe the structure and registers of the IAS computer.

Show model answer

Main memory: 1000 words of 40 bits; a word holds one number or two 20-bit instructions (8-bit opcode + 12-bit address). Registers: MBR, MAR, IR, IBR, PC, AC, MQ. It runs in fetch and execute cycles.

Q4

Differentiate computer architecture and computer organization.

Show model answer

Architecture is what the programmer sees (instruction set, data types, addressing modes, registers). Organization is how it is implemented (control signals, interfaces, memory technology, buses). One architecture can have many organizations.

Q5

Explain the different instruction formats.

Show model answer
  • 3-address: ADD R1, R2, R3; 2-address: ADD R1, R2; 1-address (accumulator): ADD X; 0-address (stack): ADD.
  • Fewer addresses give shorter instructions but need more instructions per task.
Q6

Explain any five addressing modes with the effective address.

Show model answer
  • Immediate: operand in the instruction; direct EA = A; indirect EA = (A); register EA = R; register indirect EA = (R); displacement/indexed EA = A + (R); relative EA = A + PC.
Q7

What are system buses? Explain each.

Show model answer

Data bus carries data; address bus carries the location and its width sets the addressable memory 2n; control bus carries read / write, interrupt, clock and bus request / grant signals.

P1

Number system conversion

Convert 156 to binary, octal and hexadecimal. Convert 0.625 and 25.375 to binary and 101101.101₂ to decimal.

Show solution
  1. 156 ÷ 2 repeatedly: remainders read upward give 10011100.
  2. Group in 3 bits: 010 011 100 → 2 3 4 = 234₈. Group in 4 bits: 1001 1100 → 9 C.
  3. 0.625 × 2 = 1.25 → 1; 0.25 × 2 = 0.5 → 0; 0.5 × 2 = 1.0 → 1, so 0.625 = 0.101₂.
  4. 25 = 11001; 0.375 = 0.011, so 25.375 = 11001.011₂.
  5. 101101 = 45; .101 = 0.5 + 0.125 = 0.625, so 101101.101₂ = 45.625.
156 = 10011100₂ = 234₈ = 9C₁₆; 0.625 = 0.101₂; 25.375 = 11001.011₂; 101101.101₂ = 45.625.
P2

Signed representation

Represent −45 in 8 bits in sign-magnitude, 1's complement and 2's complement. State the 8-bit 2's complement range.

Show solution
  1. 45 = 00101101.
  2. Sign-magnitude: set the sign bit → 10101101.
  3. 1's complement: invert all bits → 11010010.
  4. 2's complement: add 1 to 11010010 → 11010011 (0xD3).
  5. Range for n = 8: −2⁷ to 2⁷ − 1.
−45 = 10101101 (SM) = 11010010 (1C) = 11010011 (2C); 2's complement range −128 to +127.
P3

Instruction formats

Write programs for X = (A + B) × (C + D) using 3-, 2-, 1- and 0-address instructions.

Show solution
  1. 3-address: ADD R1, A, B; ADD R2, C, D; MUL X, R1, R2.
  2. 2-address: MOV R1, A; ADD R1, B; MOV R2, C; ADD R2, D; MUL R1, R2; MOV X, R1.
  3. 1-address: LOAD A; ADD B; STORE T; LOAD C; ADD D; MUL T; STORE X.
  4. 0-address (stack): PUSH A; PUSH B; ADD; PUSH C; PUSH D; ADD; MUL; POP X.
Instruction counts: 3, 6, 7 and 8 — fewer address fields mean more instructions.
P4

Addressing modes

Memory: M[500] = 700, M[600] = 800, M[700] = 900. Register R = 100. For an instruction LOAD with address field 500 find the value loaded under each mode.

Show solution
  1. Immediate: operand = 500.
  2. Direct: EA = 500 → M[500] = 700.
  3. Indirect: EA = M[500] = 700 → M[700] = 900.
  4. Indexed (R = 100): EA = 500 + 100 = 600 → M[600] = 800.
Immediate 500; direct 700; indirect 900; indexed 800.
P5

Memory capacity

A processor has a 24-bit address bus and 8-bit words. Find the addressable memory. How many 1K × 8 chips make a 16 KB memory, and how many address lines does 16 KB need?

Show solution
  1. 2²⁴ locations = 16 M words × 1 byte = 16 MB.
  2. Chips: 16 KB / 1 KB = 16 chips.
  3. 16 KB = 2¹⁴ bytes → 14 address lines; each chip uses 10 lines, and 4 lines select one of the 16 chips.
16 MB addressable; 16 chips; 14 address lines.
P6

IAS instruction word

In the IAS machine how many different opcodes can an instruction have and how many addresses can its address field name? How many bits does one memory word hold?

Show solution
  1. An IAS instruction is 20 bits: 8-bit opcode + 12-bit address.
  2. Opcodes: 2⁸ = 256. Address field: 2¹² = 4096 locations (memory has only 1000).
  3. A word is 40 bits = two instructions.
256 opcodes, 4096 nameable addresses, 40-bit words holding 2 instructions.
