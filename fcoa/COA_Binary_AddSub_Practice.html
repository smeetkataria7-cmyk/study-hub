1. Quick rules

AddResultSubtractResult
0+000−00
0+111−01
1+011−10
1+10 carry 10−11 borrow 1
1+1+11 carry 1
Twos complement (n bits): negate = flip all bits, then add 1. Range −2n−1 to 2n−1−1.
Subtraction: A − B = A + (−B). Negate B with twos complement, then add.
Overflow: adding two positives gives a negative, or two negatives gives a positive. Equivalent test: carry into MSB ≠ carry out of MSB. Overflow never happens when adding numbers of opposite sign.
Ignore the final carry out in twos complement; it is not an overflow by itself.

3. Answers & step-by-step solutions

A. Unsigned addition

  1. 1011 + 110 = 10001  (decimal 11 + 6 = 17)
  2. 11011 + 10101 = 110000  (decimal 27 + 21 = 48)
  3. 101101 + 11011 = 1001000  (decimal 45 + 27 = 72)
  4. 1111 + 1 = 10000  (decimal 15 + 1 = 16)
  5. 11111111 + 1 = 100000000  (decimal 255 + 1 = 256)

B. Unsigned subtraction

  1. 1101 − 101 = 1000  (decimal 13 − 5 = 8)
  2. 10110 − 1011 = 1011  (decimal 22 − 11 = 11)
  3. 100000 − 111 = 11001  (decimal 32 − 7 = 25)
  4. 11001100 − 1010101 = 1110111  (decimal 204 − 85 = 119)

C. Representation

  1. -5: +5 = 00000101 → flip = 11111010 → +1 = 11111011
  2. -18: +18 = 00010010 → flip = 11101101 → +1 = 11101110
  3. -100: +100 = 01100100 → flip = 10011011 → +1 = 10011100
  4. -1: +1 = 00000001 → flip = 11111110 → +1 = 11111111
  5. -128 = 10000000 (smallest value; +128 does not fit in 8 bits)
  6. 11101011: sign bit 1 → negative. Flip+1 = 00010101 = 21, so value = -21
  7. 10000000: sign bit 1 → negative. Flip+1 = 10000000 = 128, so value = -128
  8. 11111111: sign bit 1 → negative. Flip+1 = 00000001 = 1, so value = -1
  9. 01111111: sign bit 0 → positive = 127
  10. 10011100: sign bit 1 → negative. Flip+1 = 01100100 = 100, so value = -100

D. Add / subtract with overflow

  1. 00101101 + 00100101 = 01010010; carry into MSB = 0, carry out of MSB = 0.
    No overflow (carry-in = carry-out). Result = 82, correct.
  2. 01100100 + 00111100 = 10100000; carry into MSB = 1, carry out of MSB = 0.
    Overflow (carry-in ≠ carry-out). True answer 160 is outside -128 to 127; the bits read -96, which is wrong.
  3. 11010011 + 11011011 = 10101110; carry into MSB = 1, carry out of MSB = 1.
    No overflow (carry-in = carry-out). Result = -82, correct.
  4. 10011100 + 11000100 = 01100000; carry into MSB = 0, carry out of MSB = 1.
    Overflow (carry-in ≠ carry-out). True answer -160 is outside -128 to 127; the bits read 96, which is wrong.
  5. 45 − 37 = 45 + (-37). Negate 37: 00100101 → 11011011.
    00101101 + 11011011 = 00001000; carry into MSB = 1, carry out of MSB = 1.
    No overflow (carry-in = carry-out). Result = 8, correct.
  6. 37 − 45 = 37 + (-45). Negate 45: 00101101 → 11010011.
    00100101 + 11010011 = 11111000; carry into MSB = 0, carry out of MSB = 0.
    No overflow (carry-in = carry-out). Result = -8, correct.
  7. -20 − (-20) = -20 + (20). Negate -20: 11101100 → 00010100.
    11101100 + 00010100 = 00000000; carry into MSB = 1, carry out of MSB = 1.
    No overflow (carry-in = carry-out). Result = 0, correct.
  8. 0101 + 0011 = 1000; carry into MSB = 1, carry out of MSB = 0.
    Overflow (carry-in ≠ carry-out). True answer 8 is outside -8 to 7; the bits read -8, which is wrong.
  9. 1011 + 1100 = 0111; carry into MSB = 0, carry out of MSB = 1.
    Overflow (carry-in ≠ carry-out). True answer -9 is outside -8 to 7; the bits read 7, which is wrong.
  10. 0111 + 1101 = 0100; carry into MSB = 1, carry out of MSB = 1.
    No overflow (carry-in = carry-out). Result = 4, correct.
  11. -8 − 1 = -8 + (-1). Negate 1: 0001 → 1111.
    1000 + 1111 = 0111; carry into MSB = 0, carry out of MSB = 1.
    Overflow (carry-in ≠ carry-out). True answer -9 is outside -8 to 7; the bits read 7, which is wrong.
  12. 6 − (-6) = 6 + (6). Negate -6: 1010 → 0110.
    0110 + 0110 = 1100; carry into MSB = 1, carry out of MSB = 0.
    Overflow (carry-in ≠ carry-out). True answer 12 is outside -8 to 7; the bits read -4, which is wrong.

E. Short answers

  1. Zero uses one of the non-negative patterns (sign bit 0), so there are 128 non-negative values (0 to 127) and 128 negative values (−1 to −128). There is one extra negative number and no matching +128.
  2. Overflow occurs when both operands have the same sign bit and the result has the opposite sign bit.
  3. No. The result always lies between the two operands, so it stays inside the range.
  4. Take the twos complement of the subtrahend (flip bits, add 1), then add it to the minuend with the same adder.
