5

I/O & multiprocessors

How the computer talks to devices, and how several processors work together.
5.1

I/O devices, interfaces and modules

Devices (keyboard, display, disk, network card) differ greatly from the CPU in speed and data format, so an I/O module sits between them and the system bus.

  • Module functions: control and timing, CPU and device communication, data buffering, error detection, and status reporting.
  • Each device has registers (data, status, control) addressed through memory-mapped I/O (shares the memory address space) or isolated I/O (separate I/O instructions and address space).

5.3

Interrupt handling

  • Device raises an interrupt; the CPU finishes the current instruction, then saves PC and flags.
  • It identifies the source (vectored interrupt or polling) and jumps to the interrupt service routine.
  • After the ISR it restores the state and resumes.
  • Priority: daisy-chain, polling, or a priority interrupt controller; interrupts may be masked (disabled) and can be nested.
5.4

Direct memory access (DMA)

  • The CPU gives the DMA controller: direction (read / write), memory start address, word count, and device address.
  • The controller requests the bus (HOLD / DREQ), the CPU grants it (HLDA / DACK) and the controller transfers data directly between device and memory.
  • When the count reaches 0 it interrupts the CPU.
  • Modes: burst (block) transfer, cycle stealing (one word at a time, the CPU pauses for a cycle), transparent (only when the CPU is not using the bus).

5.6

Parallel processing

  • Doing many operations at the same time: pipeline, vector / array, multiprocessor and multicomputer systems.
  • Shared-memory multiprocessors (UMA: equal access time, SMP; NUMA: non-uniform) communicate through memory. Distributed-memory multicomputers pass messages.
  • Cache coherence and synchronisation are the main problems of shared memory.
5.7

Pipeline processing and hazards (recap)

An arithmetic or instruction pipeline splits work into stages with registers between them. The ideal gain is the number of stages; structural, data and control hazards reduce it (see 3.8). A pipeline is clocked at the slowest stage: tclk = max(tstage) + tlatch.

Theory questions and model answers

Q1

What are the functions of an I/O module?

Show model answer
  • Control and timing, communication with the CPU and with the device, data buffering, error detection and status reporting.
Q2

Compare programmed I/O, interrupt-driven I/O and DMA.

Show model answer

Programmed I/O: the CPU polls the device status in a loop (busy waiting). Interrupt-driven: the device interrupts when ready and the CPU does other work but moves each word. DMA: the controller transfers a block directly between device and memory; the CPU only starts it and handles the completion interrupt.

Q3

Explain how an interrupt is handled.

Show model answer

Finish the current instruction, save PC and flags, identify the source (vector or polling), jump to the interrupt service routine, run it, restore the state and resume. Priorities are resolved by daisy chain, polling or a controller; interrupts can be masked.

Q4

Explain DMA with its transfer modes.

Show model answer

The CPU programs the DMA controller with direction, memory address and word count. The controller requests the bus (HOLD), gets it (HLDA), transfers the data and interrupts at the end. Modes: burst, cycle stealing, transparent.

Q5

State Flynn's classification.

Show model answer

SISD (single instruction, single data: uniprocessor), SIMD (vector / array, GPU), MISD (rare), MIMD (multicore, clusters).

Q6

Differentiate shared-memory and distributed-memory multiprocessors.

Show model answer

Shared memory: processors communicate through a common memory (UMA or NUMA), with cache-coherence problems. Distributed memory: each processor has its own memory and communicates by messages.

P1

DMA vs programmed I/O

A disk transfers a 4 KB block at 4 MB/s into memory on a 500 MHz CPU. With programmed I/O the CPU copies each 4-byte word taking 50 cycles per word. Find the CPU time per block and the fraction of the CPU used. What does DMA change?

Show solution
  1. Words per block = 4096/4 = 1024.
  2. CPU cycles = 1024 × 50 = 51,200 → 51200 / 500×10⁶ = 0.1024 ms.
  3. Transfer time of the block = 4096 / 4×10⁶ = 1.024 ms.
  4. CPU fraction = 0.1024 / 1.024 = 10% (and the CPU must wait in the loop).
  5. With DMA the CPU spends only a few hundred cycles to start the transfer and process one completion interrupt.
Programmed I/O keeps the CPU busy about 10% of the time with copying; DMA frees almost all of it.
P2

Interrupt overhead

A device interrupts 1000 times per second, and each interrupt costs 2000 cycles on a 1 GHz CPU. Find the CPU time spent on interrupts.

Show solution
  1. Cycles per second = 1000 × 2000 = 2×10⁶.
  2. Fraction = 2×10⁶ / 10⁹ = 0.2%.
0.2% of the CPU is spent handling interrupts.
P3

Multiprocessor speedup

A program has 90% parallelisable work. Find the speedup and efficiency on 8 processors, and the best possible speedup.

Show solution
  1. Speedup = 1 / (0.1 + 0.9/8) = 1 / 0.2125 = 4.71.
  2. Efficiency = speedup / p = 4.71 / 8 = 58.8%.
  3. Limit = 1 / 0.1 = 10.
Speedup 4.71, efficiency 58.8%, never above 10.
P4

Flynn classification

Classify: (a) a single-core PC running one program, (b) a GPU applying the same operation to many pixels, (c) a quad-core CPU running different threads.

Show solution
  1. (a) one instruction stream, one data stream → SISD.
  2. (b) one instruction applied to many data items → SIMD.
  3. (c) several instruction streams on different data → MIMD.
(a) SISD, (b) SIMD, (c) MIMD.
P5

Memory-mapped I/O

A system has a 16-bit address bus. Addresses 0xFF00–0xFFFF are reserved for I/O (memory-mapped). How many device registers can be addressed and how much RAM space remains?

Show solution
  1. I/O range = 0xFFFF − 0xFF00 + 1 = 256 addresses.
  2. Total space = 2¹⁶ = 65,536; RAM space = 65,536 − 256 = 65,280.
  3. Decoding: the I/O select line is high when the top 8 address bits are all 1.
256 I/O registers; 65,280 locations remain for memory.
