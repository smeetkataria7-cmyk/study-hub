Central processing unit

Registers, control unit, RISC vs CISC and the pipeline.
3.1

CPU organisation

  • Registers: PC (next instruction address), IR (current instruction), MAR (memory address), MDR / MBR (data), AC / general-purpose registers, status / flag register (zero, sign, carry, overflow).
  • Data path: registers, ALU and the buses that connect them; operands travel register → ALU → register.
  • ALU takes two inputs and a function select; result goes to a register and sets the flags.
3.2

Instruction execution overview

  • Fetch the instruction from memory (address in PC), decode it, fetch operands, execute, store the result.
  • PC is incremented after each fetch; branches load a new address into PC.
3.3

Micro-operations (register transfer language)

fetch  t1: MAR ← PC  t2: MDR ← M[MAR],   PC ← PC + 1  t3: IR ← MDR

A micro-operation is an elementary step on registers in one clock pulse: register transfer (R2 ← R1), arithmetic (R3 ← R1 + R2), logic (AND, OR, XOR, complement) and shift. Conditions are written as a control function before the colon.

3.5

Microprogrammed control terms

  • Microinstruction — one control word: the signals active in one clock period. A microprogram is a sequence of them for one machine instruction.
  • Control memory holds microprograms; CAR (control address register) holds the next microinstruction address, CDR the one being executed.
  • Horizontal microcode: one bit per control signal, wide words, fast, much parallelism. Vertical microcode: encoded fields, narrow words, slower, needs decoders.
  • Sequencing: increment CAR, branch (conditional) or map the opcode to a starting address.

Pipelining

Overlap the execution of several instructions by dividing it into stages. Classic five stages: IF (fetch), ID (decode / read registers), EX (execute), MEM (memory access), WB (write back).
