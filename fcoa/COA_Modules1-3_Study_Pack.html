2. Theory questions and model answers

Module 1

Q1What are the functions and structure of a digital computer? 1.1 · p29–32

Four basic functions:

  • Data processing: arithmetic and logic on data.
  • Data storage: short-term storage of data being worked on, and long-term storage of files.
  • Data movement: input–output (I/O) with devices directly connected to the computer, and data communications over longer distances.
  • Control: a control unit manages the computer's resources and orchestrates the parts in response to instructions.

Structure (top level), four main components: the CPU (controls operation and processes data), main memory (stores data), I/O (moves data between the computer and the outside) and system interconnection (communication among CPU, memory and I/O, for example the system bus).

CPU structure: control unit, arithmetic and logic unit (ALU), registers (storage inside the CPU), and CPU interconnection (communication among the control unit, ALU and registers). The structure is described top-down in a hierarchy of components.

Q2Explain the basic functional units (top-level view of the computer). 1.1 · p109–111
  • CPU: fetches and executes instructions. It uses the memory address register (MAR) to give the memory address for the next read or write, and the memory buffer register (MBR) for the data to be written or the data just read. The I/O address register (I/OAR) specifies an I/O device and the I/O buffer register (I/OBR) carries data between an I/O module and the CPU.
  • Memory: a set of sequentially numbered locations; each location holds a binary number that can be an instruction or data.
  • I/O module: transfers data between external devices and the CPU or memory, and has internal buffers to hold the data until it can be sent on.
  • Interconnection: the buses or links connecting the three.
Q3Explain the stored-program concept (von Neumann architecture). 1.1 · p38, p109

The von Neumann architecture is based on three key concepts:

  1. Data and instructions are stored in a single read–write memory.
  2. The memory is addressable by location, without regard to the type of data stored there.
  3. Execution occurs sequentially from one instruction to the next, unless explicitly changed (by a jump or branch).

Before this, a program was a hardwired configuration of logic components, so a new task meant rewiring. With the stored-program idea the hardware is general-purpose and performs different functions depending on control signals; a unique code (an instruction) generates each set of signals. Programming then means supplying a new sequence of codes (software). The idea was proposed by von Neumann (EDVAC report, 1945) and first implemented in the IAS computer.

Q4Give an overview of the IAS computer. 1.1 · p38–44
  • Structure: a main memory (stores data and instructions), an ALU (operates on binary data), a control unit (interprets and executes the instructions in memory) and I/O equipment operated by the control unit.
  • Memory: 4,096 words of 40 bits each. A number is a sign bit and a 39-bit value. A word may instead hold two 20-bit instructions, each with an 8-bit opcode and a 12-bit address.
  • Registers: MBR (word to or from memory/I/O), MAR (address of the memory word), IR (8-bit opcode being executed), IBR (holds the right-hand instruction temporarily), PC (address of the next instruction pair), accumulator (AC) and multiplier-quotient (MQ), which hold operands and results (an 80-bit product has its high 40 bits in AC and low 40 in MQ).
  • Operation: the instruction cycle has a fetch cycle (opcode into IR, address into MAR; the instruction may come from IBR or from memory via MBR) and an execute cycle (control circuits interpret the opcode and send control signals).
  • Instruction set: 21 instructions in five groups: data transfer, unconditional branch, conditional branch, arithmetic, and address modify.

Q6Explain number systems and conversions. 1.2 · p409–419
  • A positional number system with radix r writes a number as a string of digits; digit position i has weight ri, and the value is Σ airi. Decimal has r = 10, binary r = 2 (digits 0 and 1), hexadecimal r = 16 (digits 0–9, A–F).
  • Binary to decimal: multiply each bit by its power of 2 and add. Example: 1001.1012 = 8 + 1 + 0.5 + 0.125 = 9.625.
  • Decimal to binary, integer part: divide repeatedly by 2; the remainders, read from last to first, are the binary digits.
  • Decimal to binary, fraction part: multiply repeatedly by 2; the integer part of each product (0 or 1) gives the next bit, starting from the most significant. The process may not terminate (a finite decimal fraction can need an infinite binary fraction), so it is stopped after a set number of bits.
  • Hexadecimal: each hex digit stands for 4 bits (a nibble), so conversion is by grouping bits. 1101111000012 = DE116. Hex is compact, and a binary datum usually has a multiple of 4 bits.
Q7Explain fixed-point (integer) representation: sign-magnitude and twos complement. 1.2 · p426–431
  • Unsigned: n bits give 0 to 2n − 1.
  • Sign-magnitude: the leftmost bit is the sign (0 positive, 1 negative); the other n − 1 bits are the magnitude. Drawbacks: addition and subtraction need the signs and relative magnitudes considered, and there are two representations of zero (+0 and −0).
  • Twos complement: the leftmost bit is the sign, but the weight of the leftmost bit is −2n−1: A = −2n−1an−1 + Σ 2iai. Range −2n−1 to 2n−1 − 1, one zero, and it makes addition and subtraction easy, so processors use it.
  • Negation: invert every bit (including the sign bit) and add 1. Example: +18 = 00010010 → 11101101 → 11101110 = −18.
  • Range extension (sign extension): to store an n-bit number in m > n bits, copy the sign bit into the new leftmost positions. −18 = 11101110 (8 bits) = 1111111111101110 (16 bits).
  • These are called fixed point because the binary point is fixed, to the right of the rightmost digit. Special case: the most negative number (1 followed by zeros) negates to itself.
Q8Explain floating-point representation. 1.2, 2.3 · p450–453
  • Fixed point cannot represent very large numbers or very small fractions. Floating point works like scientific notation: a number is ± S × B±E, stored in three fields: sign, significand S and exponent E. The base B is implicit.
  • The exponent is stored biased: a fixed bias (2k−1 − 1, which is 127 for 8 bits) is subtracted to get the true exponent. Biased values compare like unsigned integers.
  • A number is normalized when the significand has the form ±1.bbb…b × 2±E. The leading 1 is always present, so it is implicit and not stored.
  • Numbers are not evenly spaced: they are denser near zero. There is a trade-off between range (more exponent bits) and precision (more significand bits); only more bits raise both.
  • Possible conditions: exponent overflow, exponent underflow, significand overflow and underflow.
Q9Explain instruction formats and the design issues. 1.2 · p595–603

An instruction format defines the layout of the bits of an instruction: an opcode and zero or more operand references, each using an addressing mode (implicit or explicit via a mode field).

  • Instruction length: a trade-off between a powerful instruction set (more opcodes, operands, modes and address range) and saving space. The length should equal, or be a multiple of, the memory-transfer length (data bus width) and the character length (8 bits).
  • Allocation of bits: depends on the number of addressing modes, the number of operands, registers versus memory (8 to 32 user-visible registers is typical), the number of register sets, address range and address granularity (byte or word).
  • Variable-length opcodes give more operations for instructions that need fewer operands. Variable-length instructions give a rich repertoire compactly but make the processor more complex.
  • Examples: IAS has an 8-bit opcode and 12-bit address in 20 bits. The hypothetical machine in the book has a 16-bit instruction with a 4-bit opcode (16 opcodes) and a 12-bit address (4K words).

Q11Explain the system bus: data, address and control buses. 1.3 · p128–129, p923

A bus is a communication pathway connecting two or more devices; it is a shared transmission medium, so only one device at a time can transmit successfully (two transmitting at once garble the signals). A bus that connects the major components (processor, memory, I/O) is a system bus, with about 50 to hundreds of lines in three groups, plus power lines.

  • Data bus: carries data between modules. Its width (32, 64, 128 lines) determines how many bits transfer at a time and is a key factor in performance (a 32-bit data bus with 64-bit instructions needs two memory accesses per instruction).
  • Address bus: designates the source or destination of the data. Its width determines the maximum memory capacity. High-order bits select a module and low-order bits select a location or I/O port inside it. It also addresses I/O ports.
  • Control bus: controls the use of the data and address lines; carries command and timing signals. Typical lines: memory read, memory write, I/O read, I/O write, transfer ACK, bus request, bus grant, interrupt request, interrupt ACK, clock, reset.

Operation: to send data a module must (1) obtain the bus and (2) transfer the data. To request data it must (1) obtain the bus and (2) send a request over the control and address lines, then wait for the reply.

Q13Why are multiple-bus hierarchies and point-to-point interconnects used? 1.3 · p925–927, p130
  • With many devices on one bus, performance suffers because (1) the longer bus has more propagation delay and (2) the bus becomes a bottleneck as demand reaches its capacity. So systems use a hierarchy: a local bus (processor to cache), a system bus (main memory), an expansion bus (I/O controllers, through an interface that buffers transfers and keeps I/O traffic off the memory path) and in newer systems a high-speed bus joined by a bridge (mezzanine architecture).
  • Point-to-point interconnect (for example Intel QuickPath Interconnect, QPI) now dominates general-purpose computers because the electrical limits of fast wide synchronous buses make arbitration and synchronization hard. It has direct pairwise links (no arbitration), a layered protocol and packetized data, giving lower latency, higher data rate and better scalability. QPI has four layers: physical (20-bit phits), link (80-bit flits with an 8-bit CRC), routing and protocol.
Q14Give an overview of I/O interconnection: I/O modules and the three I/O techniques. 1.3 · p307–316
  • External devices are of three kinds: human-readable (display, printer), machine-readable (disk, tape, sensors) and communication devices. A device connects to an I/O module through control, data and status signals.
  • I/O module functions: control and timing; processor communication (command decoding, data, status reporting, address recognition); device communication; data buffering; error detection (for example a parity bit).
  • Programmed I/O: the processor controls the whole operation and repeatedly checks status, so it is busy waiting. Interrupt-driven I/O: the processor issues the command and carries on; the I/O module interrupts it when ready. DMA: the I/O module and main memory exchange data directly without the processor.

Q15Explain the basic measures of performance: clock speed, CPI, MIPS and the performance equation. 2.1 · p80–82
  • Clock speed: operations are paced by a system clock; the rate in cycles per second (Hz) is the clock rate f, and the time between pulses is the cycle time τ = 1/f. A 1 GHz processor gets 1 billion pulses per second. Most instructions take several cycles, and with pipelining several overlap, so clock speed alone does not decide performance.
  • Instruction count Ic: the number of machine instructions executed (not the number in the object code).
  • CPI (cycles per instruction): CPI = Σ(CPIi × Ii)/Ic, where CPIi is the cycles for instruction type i and Ii the number executed of that type.
  • Performance equation: T = Ic × CPI × τ. Refined: T = Ic × [p + (m × k)] × τ, where p is processor cycles to decode and execute, m the memory references, k the ratio of memory cycle time to processor cycle time.
  • MIPS rate = Ic/(T × 106) = f/(CPI × 106). MFLOPS counts floating-point operations per second (in millions).
  • Four things affect these factors: the instruction set architecture, compiler technology, processor implementation, and the cache and memory hierarchy.
  • Limitation of MIPS: it is not valid for comparing different architectures. A = B + C is one CISC instruction but four RISC instructions (load, load, add, store). A CISC at 1 MIPS and a RISC at 4 MIPS do the same work in the same time.
Q16State and explain Amdahl's law. 2.1 · p76–78

Amdahl's law (Gene Amdahl, 1967) gives the potential speedup of a program on multiple processors. A fraction (1 − f) of the time is inherently sequential and a fraction f is infinitely parallelizable with no overhead. With N processors:

Speedup = T / [T(1 − f) + Tf/N] = 1 / [(1 − f) + f/N]

Two conclusions: (1) when f is small, parallel processors have little effect; (2) as N → ∞ the speedup is bounded by 1/(1 − f), so there are diminishing returns from adding processors. So software must be adapted to highly parallel execution to exploit multicore machines.

Generalized form for any enhancement: if a feature is used a fraction f of the time before enhancement and is sped up by SUf, the overall speedup is 1/[(1 − f) + f/SUf]. Example: floating-point takes 40% of the time and is sped up K times: speedup = 1/(0.6 + 0.4/K), so the maximum (K → ∞) is 1/0.6 = 1.67.

Q17Explain addition and subtraction of twos complement integers, and overflow. 2.2 · p432–436
  • Addition: add as if the numbers were unsigned; a carry out of the leftmost bit is ignored. The result is correct if it fits.
  • Subtraction rule: to subtract the subtrahend from the minuend, take the twos complement of the subtrahend and add it: A − B = A + (−B).
  • Overflow rule: if two numbers are added and they are both positive or both negative, overflow occurs if and only if the result has the opposite sign. Overflow can occur with or without a carry. The ALU sets an overflow flag, and the result must not be used.
  • Hardware: a binary adder fed from registers A and B, a twos complementer on the B path used for subtraction, and a 1-bit overflow flag. Control signals decide whether the complementer is used.
  • Negation special cases: the negation of 0 is 0 (carry ignored); the negation of the most negative number (1000…0) is itself, an unavoidable anomaly.
Q18Explain unsigned binary multiplication and its hardware. 2.2 · p437–439
  • Multiplication forms one partial product per multiplier bit (0 if the bit is 0, the multiplicand if it is 1), each shifted one place left, then sums them. The product of two n-bit numbers has up to 2n bits.
  • Hardware: multiplicand in M, multiplier in Q, a register A (initially 0) and a carry bit C (initially 0). The control logic reads Q0: if it is 1, add M to A (carry into C); then shift C, A, Q right by one bit. Repeat n times; the product is in A and Q. Add and shift for each 1, shift only for each 0.

The method fails for negative numbers in twos complement, which is why Booth's algorithm is used.

Q19Explain Booth's algorithm for twos complement multiplication. 2.2 · p440–446

Booth's algorithm multiplies twos complement numbers of any sign without correcting signs, and it is faster because blocks of 1s or 0s in the multiplier are skipped.

  • Registers: multiplicand in M, multiplier in Q, A = 0 and an extra 1-bit register Q−1 = 0 to the right of Q0.
  • Steps (repeat n times): look at Q0 and Q−1.
    • 0 0 or 1 1: do nothing but shift.
    • 0 1: A ← A + M.
    • 1 0: A ← A − M.
    Then do an arithmetic right shift of A, Q, Q−1 (the leftmost bit of A is kept as well as shifted, preserving the sign). The product is in A:Q.
  • Why it works: a block of 1s can be written as a difference of powers of 2: 2n + … + 2n−K = 2n+1 − 2n−K. So 00011110 = 25 − 21: one subtraction at the first 1 of the block (1–0) and one addition at its end (0–1). It also works for a negative multiplier.
Q20Explain the restoring division algorithm. 2.2 · p446–449

Division follows paper-and-pencil long division with repeated shift and subtract. The divisor goes in M, the dividend in Q, and A = 0. For n bits, repeat n times:

  1. Shift A and Q left by one bit.
  2. Subtract: A ← A − M.
  3. If A ≥ 0 (sign bit 0), set Q0 = 1. If A < 0 (sign bit 1), set Q0 = 0 and restore A by adding M back.

At the end the quotient is in Q and the remainder in A. Names: "restoring" because a failed subtraction is undone. The algorithm assumes positive operands with |V| < |D| (and a dividend that is a 2n-bit positive number). For signed numbers, divide the magnitudes and fix the signs: D = Q × V + R, sign(R) = sign(D), sign(Q) = sign(D) × sign(V). Example: 7 ÷ 3 gives Q = 2, R = 1; 7 ÷ (−3) gives Q = −2, R = 1; (−7) ÷ 3 gives Q = −2, R = −1.

Q21Explain the IEEE 754 floating-point standard (single and double precision). 2.3 · p453–458
  • IEEE 754 (1985, revised 2008) was developed so programs port between processors. The three basic binary formats are 32, 64 and 128 bits.
  • Single (32 bits): 1 sign bit, 8 exponent bits (bias 127), 23 fraction bits. Double (64 bits): 1 sign, 11 exponent bits (bias 1023), 52 fraction bits. Normal value = (−1)S × 1.F × 2(E − bias); the leading 1 is implied, giving a 24-bit (or 53-bit) significand.
  • Single: exponent field 1 to 254, true exponent −126 to +127; range about 10−38 to 10+38. Double: 1 to 2046, −1022 to +1023; about 10−308 to 10+308.
  • Special values: exponent 0 with fraction 0 is ±0; exponent all 1s with fraction 0 is ±∞; exponent all 1s with fraction nonzero is NaN (quiet or signaling); exponent 0 with fraction nonzero is a subnormal number (0.F × 2−126), which gives gradual underflow.
  • Four rounding modes: round to nearest (default; ties go to even), round toward +∞, round toward −∞, round toward 0 (truncation).
Q22Explain floating-point addition, subtraction, multiplication and division. 2.3 · p459–467
  • Add/subtract (harder, because of alignment) has four phases: (1) zero check (for subtraction first change the sign of the subtrahend; if an operand is 0 the other is the result); (2) align the significands: shift the smaller number right and increase its exponent until the exponents are equal (the smaller number is shifted so any lost digits are of small significance); (3) add or subtract the significands (a carry may need a right shift and an exponent increment); (4) normalize (shift left, decrement the exponent) and round.
  • Multiplication: if either operand is 0 the result is 0; add the exponents (with biased exponents subtract the bias once, because the sum doubles it); check for exponent overflow or underflow; multiply the significands (product is double length); normalize and round.
  • Division: a zero divisor gives an error or infinity, and a zero dividend gives 0; subtract the exponents (add the bias back); divide the significands; normalize and round.
  • Guard bits are extra bits at the right end of the significand in the ALU registers so alignment does not lose precision.
  • Conditions: exponent overflow (too large, reported as ±∞), exponent underflow (too small, may be reported as 0), significand underflow (digits shifted off while aligning, so rounding is needed) and significand overflow (a carry out of the most significant bit, fixed by realignment).

Q23Explain the CPU organization. 3.1 · p655

The processor must fetch an instruction, interpret it, fetch data, process data and write data. To do this it needs a small internal memory, so it contains:

  • The ALU, which does the actual computation.
  • The control unit (CU), which controls the movement of data and instructions into and out of the processor and controls the ALU.
  • Registers (the internal memory).
  • An internal processor bus that carries data between the registers and the ALU, because the ALU works only on data in the internal memory.

The processor's internal structure mirrors the computer's: a few major elements joined by data paths.

Q24Explain the register organization of a CPU. 3.1 · p657–660

Registers form the top of the memory hierarchy and play two roles:

  • User-visible registers (referenced by machine language, so the programmer can minimize memory references): general-purpose (any function), data registers (hold data only), address registers (segment pointers, index registers, stack pointer) and condition codes (flag bits set by hardware after operations, tested by conditional branches). Design issues: general vs specialized registers, number of registers (8 to 32 is typical), and register length.
  • Control and status registers: the four essential ones are the program counter (PC) (address of the next instruction), instruction register (IR) (the instruction just fetched), memory address register (MAR) (connected to the address bus) and memory buffer register (MBR) (connected to the data bus). The program status word (PSW) holds condition codes and status: sign, zero, carry, equal, overflow, interrupt enable/disable and supervisor mode.
Q25Explain the instruction cycle and the data path in each cycle. 3.1 · p112–116, p119, p663–666

An instruction cycle is the processing needed for one instruction: fetch (read the next instruction from memory into the IR, with the PC pointing to it and then incremented), indirect (fetch indirect operand addresses, if any), execute (decode the opcode and perform the operation) and interrupt (if an enabled interrupt is pending, save the context and jump to the handler). Only fetch and execute always occur.

Actions during execute fall into four categories: processor–memory, processor–I/O, data processing and control (change the sequence).

State diagram of one instruction: instruction address calculation (iac), instruction fetch (if), instruction operation decoding (iod), operand address calculation (oac), operand fetch (of), data operation (do) and operand store (os).

Data flow:

  • Fetch: PC → MAR → address bus; the control unit requests a memory read; the data returns on the data bus into the MBR, then to the IR; the PC is incremented.
  • Indirect: the address field of the MBR goes to the MAR; read memory; the operand address arrives in the MBR.
  • Interrupt: the PC contents go to the MBR to be saved in memory at the location in the MAR (for example the stack pointer); the PC is loaded with the address of the interrupt routine.
Q26What are micro-operations? Give the sequences for the fetch, indirect and interrupt cycles and examples of the execute cycle. 3.1 · p807–813

A micro-operation is the simplest, atomic step of a processor, usually a movement of data between registers or an ALU operation. A program is a sequence of instructions, each instruction cycle is made of subcycles (fetch, indirect, execute, interrupt), and each subcycle is a series of micro-operations, each taking one time unit (clock pulse). All micro-operations are one of: register to register, register to external interface, external interface to register, or an arithmetic or logic operation with registers.

The control unit uses clock, IR, flags and control-bus signals as inputs and sends control signals to move data, drive the ALU and the system bus (p814–818).

N1: Base conversions

  1. (a) 156 to binary (divide by 2, read remainders from the bottom): 156 ÷ 2 = 78 r 0; 78 ÷ 2 = 39 r 0; 39 ÷ 2 = 19 r 1; 19 ÷ 2 = 9 r 1; 9 ÷ 2 = 4 r 1; 4 ÷ 2 = 2 r 0; 2 ÷ 2 = 1 r 0; 1 ÷ 2 = 0 r 1. Reading upwards: 10011100. Check: 128 + 16 + 8 + 4 = 156.
  2. (b) 0.6875 to binary (multiply by 2, take the integer part): 0.6875 × 2 = 1.375 → 1; 0.375 × 2 = 0.75 → 0; 0.75 × 2 = 1.5 → 1; 0.5 × 2 = 1.0 → 1; fraction is now 0, so stop. Bits in order: 0.1011.
  3. (c) 1011.1012 = 8 + 0 + 2 + 1 + 0.5 + 0 + 0.125 = 11.625.
  4. (d) 110111100001: group in fours: 1101 | 1110 | 0001 = D | E | 1 = DE116.
  5. (e) 2F16 = 2 × 16 + 15 = 47; binary: 2 = 0010, F = 1111, so 00101111.

N2: Twos complement

  1. (a) −45: +45 = 00101101. Invert: 11010010. Add 1: 11010011.
  2. (b) 11101110: the sign bit is 1, so negate: invert 00010001, add 1 = 00010010 = 18. The value is −18. (Check with weights: −128 + 64 + 32 + 8 + 4 + 2 = −18.)
  3. (c) Sign extension: 11101110 is negative, so copy the sign bit 1 into the eight new left positions: 1111111111101110.
  4. (d) Range −2n−1 to 2n−1 − 1: 8 bits: −128 to +127; 16 bits: −32768 to +32767.

N3: Addition, subtraction and overflow (8 bits)

  1. (a) 100 + 50: 01100100 + 00110010 = 10010110. Two positives gave a negative result (sign bit 1), so overflow (the true sum 150 exceeds 127).
  2. (b) (−90) + (−50): −90 = 10100110 and −50 = 11001110. Sum = 1 01110100; ignore the carry out: 01110100. Two negatives gave a positive result, so overflow (the true sum −140 is below −128).
  3. (c) 25 − 18: 25 = 00011001, 18 = 00010010, so −18 = 11101110. 00011001 + 11101110 = 1 00000111; ignore the carry: 00000111 = 7. The operands to the addition have opposite signs, so no overflow.

N7: IEEE 754 conversions

  1. (a) 13.625: 13 = 1101 and 0.625 = 0.101, so 13.625 = 1101.1012 = 1.101101 × 23 (move the point 3 places). Sign = 0. Biased exponent = 3 + 127 = 130 = 10000010. Fraction (drop the leading 1) = 101101 followed by zeros to 23 bits. Bits: 0 | 10000010 | 10110100000000000000000. Grouped in fours: 0100 0001 0101 1010 0000 … = 0x415A0000.
  2. (b) −0.15625: 0.15625 = 0.001012 = 1.01 × 2−3. Sign = 1. Exponent = −3 + 127 = 124 = 01111100. Fraction = 01 then zeros. Bits: 1 | 01111100 | 01000000000000000000000 = 1011 1110 0010 0000 … = 0xBE200000.
  3. (c) 0x42280000 = 0100 0010 0010 1000 0…: sign 0; exponent 10000100 = 132 → true exponent 5; fraction 0101 → 1.0101 × 25 = 1010102 = 42. 0xC1480000 = 1100 0001 0100 1000 0…: sign 1; exponent 10000010 = 130 → 3; fraction 1001 → 1.1001 × 23 = 1100.12 = 12.5, so −12.5.
  4. (d) −2.5 in double: 2.5 = 10.12 = 1.01 × 21. Sign 1. Exponent = 1 + 1023 = 1024 = 10000000000 (11 bits). Fraction = 01 then 50 zeros. Bits: 1 | 10000000000 | 0100…0 = 1100 0000 0000 0100 0… = 0xC004000000000000.

N8: Floating-point addition and multiplication

(a) 0.5 + 0.4375

  1. Write both as normalized binary: 0.5 = 1.000 × 2−1; 0.4375 = 0.01112 = 1.110 × 2−2.
  2. Zero check: neither is zero.
  3. Align: the smaller exponent is −2, so shift 1.110 × 2−2 right one place and increase its exponent: 0.111 × 2−1.
  4. Add the significands: 1.000 + 0.111 = 1.111, with exponent −1.
  5. Normalize: 1.111 is already normalized. Result = 1.111 × 2−1 = 0.11112 = 0.9375 (= 0.5 + 0.4375).

(b) 1.5 × 2.5

  1. 1.5 = 1.1 × 20; 2.5 = 1.01 × 21.
  2. Add the exponents: 0 + 1 = 1. (With stored biased exponents, 127 + 128 = 255, so subtract the bias 127 to get 128, which is true exponent 1.)
  3. Multiply the significands: 1.1 × 1.01 = 1.111 (1.5 × 1.25 = 1.875).
  4. Normalize: already normalized. Result = 1.111 × 21 = 11.112 = 3.75.

N9: CPI, MIPS and time

  1. CPI = Σ(CPIi × fractioni) = (1 × 0.6) + (2 × 0.18) + (4 × 0.12) + (8 × 0.1) = 0.6 + 0.36 + 0.48 + 0.8 = 2.24.
  2. MIPS = f/(CPI × 106) = (400 × 106)/(2.24 × 106) = ≈ 178.
  3. T = Ic × CPI × τ = 2 × 106 × 2.24 / (400 × 106) = 0.0112 s = 11.2 ms.

N10: Comparing two machines

  1. Time per instruction = CPI/f. A: 1.5/(2 × 109) = 0.75 ns. B: 2.5/(3 × 109) = 0.833 ns.
  2. For the same program (same Ic), A is faster: speed ratio = 0.833/0.75 = 1.11.
  3. MIPS: A = 2000/1.5 = 1333; B = 3000/2.5 = 1200.

B has the higher clock rate, but its higher CPI makes it slower. Clock rate alone does not decide performance.

N11: Amdahl's law

  1. (a) f = 0.4, SUf = 4: speedup = 1/[(1 − 0.4) + 0.4/4] = 1/(0.6 + 0.1) = 1/0.7 = 1.43. Maximum (SUf → ∞): 1/0.6 = 1.67.
  2. (b) f = 0.8, N = 8: speedup = 1/[0.2 + 0.8/8] = 1/(0.2 + 0.1) = 3.33. As N → ∞: 1/0.2 = 5.

The sequential 20% limits the speedup to 5 however many processors are added.

N15: Micro-operations

  1. (a) Fetch: t1: MAR ← (PC); t2: MBR ← Memory, PC ← (PC) + I; t3: IR ← (MBR). I is the instruction length.
  2. (b) ADD R1, X (direct): t1: MAR ← (IR(address)); t2: MBR ← Memory; t3: R1 ← (R1) + (MBR) (the addition is done by the ALU).
  3. Which can share a time unit: MBR ← Memory and PC ← (PC) + I do not interfere, so they share t2 (fetch is three steps but four micro-operations). Also IR ← (MBR) could be grouped with PC ← (PC) + I in t3.
  4. Which cannot: MAR ← (PC) must come before MBR ← Memory (the read uses the address in the MAR), and MBR ← Memory and IR ← (MBR) must not be in the same time unit (read and write the same register conflict).

N16: Instruction format sizes

  2. (b) Address bits = 32 − 8 − 5 = 19. Directly addressable words = 219 = 524,288 (512K) words.
