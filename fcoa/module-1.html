Structure of a computer

Parts, stored programs, data representation, instructions and buses.
1.1

Functions of a computer

  • Data processing — arithmetic and logic on data.
  • Data storage — short-term (registers, memory) and long-term (disk).
  • Data movement — between the computer and the outside world (I/O) and between its own parts (communication).
  • Control — coordinates the other three.
1.2

Structure of a digital computer

Four main parts joined by the system interconnection (buses): CPU, main memory, I/O modules.

  • CPU = control unit + ALU + registers + CPU interconnection.
  • Control unit — fetches and decodes instructions and issues control signals.
  • ALU — performs arithmetic and logical operations.
  • Registers — fast storage inside the CPU.
1.3

Basic functional units

  • Input unit, output unit, memory (main and secondary), ALU, control unit.
  • The ALU and control unit together form the processor.
1.4

Stored-program concept (von Neumann)

Instructions and data are stored together in the same read-write memory, addressed by location and not by type. The CPU fetches instructions one after another using the program counter (sequential execution). This idea removes the need to rewire the machine to change the program.

1.5

IAS computer

  • Main memory: 1000 words of 40 bits each (addresses 0–999).
  • A word holds one number (sign + 39 bits) or two 20-bit instructions: 8-bit opcode + 12-bit address each.
  • Registers: MBR (memory buffer), MAR (memory address), IR (instruction register), IBR (instruction buffer, holds the right instruction), PC, AC (accumulator) and MQ (multiplier quotient).
  • Works in a repeated fetch (instruction into IR) and execute cycle; the right-hand instruction is taken from IBR without a memory access.

1.9

Instruction formats

An instruction has an opcode and zero or more operand fields. Formats by number of addresses:

  • 3-address: ADD R1, R2, R3 (R1 ← R2 + R3).
  • 2-address: ADD R1, R2 (R1 ← R1 + R2).
  • 1-address: ADD X (AC ← AC + M[X]), uses the accumulator.
  • 0-address: stack machines, ADD pops two and pushes the sum.
  • Opcode bits decide how many operations exist: 2opcode bits.

1.11

System buses

addressable memory  2nbandwidth  bus width × transfers per second
  • Data bus — carries data; its width sets how many bits move at once.
  • Address bus — carries the memory / I/O address; n lines address 2n locations.
  • Control bus — read / write, interrupt, clock, bus request / grant signals.
1.12

Bus interconnection and I/O mechanisms

Many devices share a bus, so arbitration decides who may use it (centralised or distributed). Single-bus designs are cheap but slow; multiple buses (local, system, expansion) reduce contention. I/O modules connect devices to the buses (detail in Module 5).
