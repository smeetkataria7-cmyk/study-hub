Vector spaces & transformations

Bases, inner products, Gram–Schmidt and linear maps.
4.1

Vector space

A set V over the reals with vector addition and scalar multiplication that satisfy closure and these eight axioms:

  • Addition: commutative, associative, a zero vector 0, an additive inverse −v for every v.
  • Scalars: a(bv) = (ab)v, 1v = v, a(u + v) = au + av, (a + b)v = av + bv.
  • Examples: Rn, polynomials of degree ≤ n, m × n matrices, continuous functions on an interval.
  • Consequences: 0v = 0, a0 = 0, (−1)v = −v.
4.2

Subspace

A subset W of V is a subspace iff:

  • 0 ∈ W (non-empty).
  • Closed under addition: u, v ∈ W ⇒ u + v ∈ W.
  • Closed under scalar multiplication: v ∈ W ⇒ cv ∈ W.
  • The intersection of subspaces is a subspace; the union usually is not. A plane not through the origin is not a subspace.
4.3

Linear combination, span, independence

  • Linear combination: c1 v1 + … + ck vk. Span = set of all of them (a subspace).
  • Independent: c1 v1 + … + ck vk = 0 only when every ci = 0; otherwise dependent.
  • Test in Rn: put the vectors as rows, row-reduce; independent iff the rank equals the number of vectors (or det ≠ 0 for n vectors in Rn).
  • More than n vectors in Rn are always dependent; a set containing 0 is dependent.

4.4

Basis and dimension

  • A basis is a linearly independent set that spans V; every vector has a unique coordinate expression.
  • Dimension = number of vectors in any basis (the same for all bases).
  • dim Rn = n, dim Pn = n + 1, dim Mm×n = mn.
  • In an n-dimensional space any n independent vectors, or any n spanning vectors, form a basis.
4.5

Rank and nullity

rank(A) + nullity(A) = n (number of columns)

Rank = number of pivots = dimension of the row space = dimension of the column space. Nullity = dimension of the null space { x : Ax = 0 } = number of free variables.

4.6

Inner product, norm and distance

⟨u, v⟩ = u1 v1 + … + un vn‖u‖ = ⟨u, u⟩,   d(u, v) = ‖u − v‖cos θ = ⟨u, v⟩‖u‖ ‖v‖
  • Axioms: symmetric, linear in each argument, positive definite (⟨v, v⟩ > 0 for v ≠ 0).
  • Cauchy–Schwarz: |⟨u, v⟩| ≤ ‖u‖‖v‖. Triangle: ‖u + v‖ ≤ ‖u‖ + ‖v‖.
  • Orthogonal if ⟨u, v⟩ = 0; orthonormal if also unit length.
4.7

Orthogonal complement and projection

W⊥ = { v : ⟨v, w⟩ = 0   for all   w ∈ W }proju v = ⟨v, u⟩⟨u, u⟩ udim W + dim W⊥ = n

W⊥ is a subspace and every v splits uniquely as v = w + w⊥. The projection onto W with an orthogonal basis u1, …, uk is the sum of the projections onto each ui.

Converts a basis v1, …, vn into an orthogonal basis u1, …, un (then orthonormal ek) spanning the same subspaces at each step.

4.9

Linear transformation

T(u + v) = T(u) + T(v),   T(c u) = c T(u)
  • Equivalent: T(au + bv) = aT(u) + bT(v); always T(0) = 0.
  • Matrix: for T: Rn → Rm, T(x) = Ax where the columns of A are T(e1), …, T(en).
  • Kernel ker T = { v : T(v) = 0 } (null space); range (image) = column space of A.
  • T is one-to-one iff ker T = {0}; onto iff range = codomain. Composition corresponds to matrix multiplication.
4.10

Rank–nullity theorem

dim(ker T) + dim(range T) = dim V

Nullity of T + rank of T = dimension of the domain. A linear map from a smaller-dimensional space into a larger one cannot be onto; from larger to smaller cannot be one-to-one.
