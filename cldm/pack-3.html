Graphs & trees

Connectivity, Euler and Hamilton, spanning trees and Huffman coding.
3.1

Graph terminology

handshake  Σ deg(v) = 2|E|
  • A graph G = (V, E); order = |V|, size = |E|. Degree of a vertex = edges at it (a loop counts 2).
  • Simple graph: no loops or multiple edges. Multigraph: parallel edges allowed. Directed graph: ordered pairs (in-degree, out-degree).
  • Subgraph, complement (edges exactly where G has none), regular graph (all degrees equal), weighted graph.
3.2

Special graphs

  • Complete Kn: every pair adjacent; n(n − 1)2 edges, regular of degree n − 1.
  • Bipartite: vertices split into two sets with edges only between them; equivalently no odd cycle, or 2-colourable. Complete bipartite Km,n has mn edges.
  • Cycle Cn (n edges), path Pn, wheel Wn, cube Qn (2n vertices).
  • Planar: can be drawn without crossings; Euler: V − E + F = 2.
3.3

Graph isomorphism

G1 ≅ G2 if there is a bijection V1 → V2 that preserves adjacency (equivalently, a permutation of the adjacency matrix).

  • Necessary conditions (if any fails, not isomorphic): same number of vertices and edges, same degree sequence, same number of cycles of each length, same connectivity.
  • These are not sufficient: finally exhibit the mapping and check every edge.
3.4

Connectivity

κ(G) ≤ λ(G) ≤ δ(G)
  • Walk (repeated vertices and edges allowed) ⊃ trail (no repeated edge) ⊃ path (no repeated vertex). A closed trail is a circuit; a closed path a cycle.
  • Connected: a path between every pair. Components partition the graph.
  • Cut vertex / bridge: removing it disconnects the graph.
  • Vertex connectivity κ(G) and edge connectivity λ(G): minimum vertices / edges whose removal disconnects the graph.
3.5

Distance, centre, radius, diameter

  • Distance d(u, v) = length of a shortest path.
  • Eccentricity e(v) = largest distance from v to any vertex.
  • Radius = smallest eccentricity; diameter = largest eccentricity.
  • Centre = set of vertices whose eccentricity equals the radius.

3.6

Eulerian graphs and the bridge problem

  • Euler circuit (uses every edge once, returns to start) exists in a connected graph iff every vertex has even degree.
  • Euler path (not closed) exists iff exactly 0 or 2 vertices have odd degree; it starts and ends at the odd ones.
  • Königsberg bridges: the four land areas have degrees 3, 3, 3, 5, all odd, so no walk crosses each bridge exactly once.
3.7

Hamiltonian graphs

  • A Hamilton cycle visits every vertex exactly once and returns to the start. No simple necessary-and-sufficient test exists.
  • Dirac: simple graph with n ≥ 3 and every degree ≥ n/2 is Hamiltonian.
  • Ore: deg(u) + deg(v) ≥ n for every non-adjacent pair suffices.
  • Kn has (n − 1)!2 distinct Hamilton cycles.
3.8

Travelling salesperson problem (TSP)

Find the minimum-weight Hamilton cycle in a weighted complete graph.

  • Brute force: try (n − 1)!/2 tours.
  • Nearest neighbour: start anywhere, always go to the nearest unvisited vertex, return at the end. Fast but not always optimal.

3.9

Trees

  • A tree is a connected graph with no cycle. Equivalent: connected with n − 1 edges; unique path between any two vertices; removing any edge disconnects it.
  • Every tree with n ≥ 2 has at least two leaves.
  • Rooted m-ary tree with i internal vertices: n = m i + 1 vertices and l = (m − 1) i + 1 leaves. Full binary tree: l = i + 1.
  • Tree isomorphism: compare degree sequences, the centre, then match rooted subtrees recursively.
3.10

Minimal spanning tree (MST)

  • A spanning tree contains all vertices and n − 1 edges; Kn has nn−2 (Cayley).
  • Kruskal: sort edges by weight; add the next edge unless it forms a cycle; stop at n − 1 edges.
  • Prim: grow one tree from a start vertex, always adding the cheapest edge leaving the tree.
  • Both give a minimum total weight.

3.11

Prefix codes and Huffman procedure

average length  Σ wi ℓiΣ wi
  • A prefix code has no codeword that is the beginning of another, so a bit string decodes uniquely with no separators. Codewords are the leaves of a binary tree (0 = left, 1 = right).
  • Huffman: repeatedly merge the two smallest weights into a new node until one tree remains; label branches 0 / 1. Frequent symbols get short codes and the average length is minimal.

Q

Theory questions and model answers

Tap "Show model answer" to reveal.
Q1

State the handshaking lemma. What does it imply?

Show model answer

The sum of the degrees equals twice the number of edges: Σ deg(v) = 2|E|. Hence the number of odd-degree vertices is even.

Q2

Define a bipartite graph and give a test for it.

Show model answer

A graph whose vertex set splits into two sets with every edge between them. Test: it is 2-colourable, equivalently it has no odd cycle. Km,n has mn edges.

Q3

How do you decide whether two graphs are isomorphic?

Show model answer

First check invariants: same numbers of vertices and edges, same degree sequence, same cycle lengths, same connectivity. If all agree, exhibit a bijection and verify that every edge is preserved.

Q4

State the conditions for Euler circuits and Euler paths.

Show model answer

A connected graph has an Euler circuit iff every vertex has even degree, and an Euler path iff exactly 0 or 2 vertices have odd degree. Königsberg has four odd vertices, so no walk crosses each bridge once.

Q5

Define Hamiltonian graph; state Dirac and Ore theorems.

Show model answer

A Hamilton cycle visits each vertex once. Dirac: n ≥ 3 and every degree ≥ n/2 ⇒ Hamiltonian. Ore: deg u + deg v ≥ n for all non-adjacent pairs ⇒ Hamiltonian.

Q6

Explain Kruskal's and Prim's algorithms for the MST.

Show model answer

Kruskal: sort edges, add the cheapest edge that does not form a cycle. Prim: grow one tree, always adding the cheapest edge leaving it. Both give a minimum spanning tree.

Q7

Explain prefix codes and the Huffman procedure.

Show model answer

A prefix code has no codeword that is the start of another, so decoding is unique. Huffman repeatedly merges the two least-weight nodes; frequent symbols get shorter codes and the average length is minimal.

Practice problems with solutions

Try each one first, then open the solution.
P1

Degrees and edges

A graph has 10 vertices, each of degree 3. How many edges does it have? How many edges has K₇, and K₃,₄?

Show solution
  1. Sum of degrees = 10 × 3 = 30 = 2|E| → |E| = 15.
  2. K₇: 7·6/2 = 21 edges.
  3. K₃,₄: 3 × 4 = 12 edges.
15, 21 and 12 edges.
P2

Isomorphism

Are the 4-cycle with edges 01, 02, 13, 23 and the 4-cycle with edges 01, 12, 23, 30 isomorphic? Is the first isomorphic to the star K₁,₃?

Show solution
  1. Both have 4 vertices, 4 edges and degree sequence (2, 2, 2, 2).
  2. A bijection exists: 0→0, 1→1, 2→3, 3→2 preserves every edge.
  3. The star has 3 edges and degrees (3, 1, 1, 1), so it differs.
The two 4-cycles are isomorphic (mapping found by search); the 4-cycle is not isomorphic to the star.
P3

Euler and Hamilton

A connected graph has degrees 2, 2, 3, 3, 4, 4. Does it have an Euler circuit or an Euler path?

Show solution
  1. Two vertices (degree 3) have odd degree.
  2. An Euler circuit needs all even degrees, so no circuit.
  3. Exactly 2 odd vertices → an Euler path exists, starting and ending at the two degree-3 vertices.
No Euler circuit, but an Euler path exists.
P4

Distance, radius and centre

Graph edges: 1–2, 1–3, 2–4, 3–4, 3–5, 4–6, 5–6. Find the eccentricities, radius, diameter and centre.

Show solution
  1. Eccentricity = longest shortest-path distance from each vertex: e(1) = 3, e(2) = 3, e(3) = 2, e(4) = 2, e(5) = 3, e(6) = 3.
  2. Radius = min = 2; diameter = max = 3.
  3. Centre = vertices with eccentricity 2.
Radius 2, diameter 3, centre {3, 4}.
P5

Minimum spanning tree

Weighted graph: ab 2, ac 3, bc 1, bd 4, cd 5, ce 6, de 2. Find an MST with Kruskal's algorithm.

Show solution
  1. Sorted edges: bc(1), ab(2), de(2), ac(3), bd(4), cd(5), ce(6).
  2. Accept bc (1)
  3. Accept ab (2)
  4. Accept de (2)
  5. Accept bd (4)
  6. Edges that would close a cycle are skipped.
MST: bc, ab, de, bd with total weight 9.
P6

Huffman coding

Frequencies: A 45, B 13, C 12, D 16, E 9, F 5. Build Huffman codes and the average length.

Show solution
  1. Merge the two smallest repeatedly: F5 + E9 = 14; C12 + B13 = 25; 14 + D16 = 30; 25 + 30 = 55; A45 + 55 = 100.
  2. Codes: A = 0, B = 101, C = 100, D = 111, E = 1101, F = 1100.
  3. Average length = Σ weight × length / 100 = 2.24 bits.
Average 2.24 bits per symbol (3 for fixed-length coding).
P7

Travelling salesperson

Five cities: AB 12, AC 10, AD 19, AE 8, BC 3, BD 7, BE 2, CD 6, CE 20, DE 4. Find the nearest-neighbour tour from A and the optimal tour.

Show solution
  1. Nearest neighbour from A: A → E → B → C → D → A, cost 38.
  2. Brute force over all 24 orderings of B, C, D, E (12 distinct tours): best tour A → C → B → D → E → A.
Nearest neighbour cost 38; optimal cost 32.
