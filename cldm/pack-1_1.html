Vector calculus

Gradient, divergence, curl, Jacobian, Hessian and optimisation.
1.1

Scalar and vector functions

A scalar field f(x, y, z) assigns a number to each point; a vector field F = Pi + Qj + Rk assigns a vector. The operator ∇ = i ∂/∂x + j ∂/∂y + k ∂/∂z builds the other quantities.

1.2

Gradient

∇f = (∂f∂x,   ∂f∂y,   ∂f∂z)
  • Points in the direction of maximum increase of f; its length is the maximum rate of increase.
  • Normal to the level surface f = c.
  • ∇(fg) = f∇g + g∇f; ∇f(r) = f'(r) r/r with r = |r|.
1.3

Directional derivative

Du f = ∇f · u

Rate of change of f at a point along the unit vector u. Maximum value is |∇f| (along ∇f); minimum is −|∇f|; zero along the level curve. Normalise the direction first.

1.4

Divergence

div F = ∇ · F = ∂P∂x + ∂Q∂y + ∂R∂z

A scalar: net outflow per unit volume. If div F = 0 the field is solenoidal (incompressible).

1.5

Curl

curl F = ∇ × F = (∂R∂y − ∂Q∂z,   ∂P∂z − ∂R∂x,   ∂Q∂x − ∂P∂y)

A vector: local rotation. If curl F = 0 the field is irrotational (conservative), so F = ∇φ for a scalar potential φ.

1.6

Laplacian

∇2 f = ∂2 f∂x2 + ∂2 f∂y2 + ∂2 f∂z2

∇2 f = 0 means f is harmonic. ∇2 f = ∇ · (∇f).

1.7

Identities to remember

curl(grad f) = 0,   div(curl F) = 0div(f F) = f · div F + ∇f · Fcurl(f F) = f · curl F + ∇f × F∇ · r = 3,   ∇ × r = 0,   ∇ rn = n rn−2 rdiv(rn r) = (n + 3) rn,   ∇2 rn = n(n + 1) rn−2

Here r is the position vector and r its length. For n = −3, r−3 r is solenoidal.

1.8

Angle between surfaces

cosθ = n1 · n2|n1||n2|,   ni = ∇ fi

The angle between two surfaces at a point is the angle between their normals ∇f1 and ∇f2 at that point. Surfaces are orthogonal when n1 · n2 = 0.

1.9

Jacobian

J = ∂(f1, f2)∂(x, y) = [ ∂f1∂x   ∂f1∂y ;   ∂f2∂x   ∂f2∂y ]

Matrix of all first partials of a vector function; row i is the gradient of fi. Its determinant scales areas / volumes in a change of variables, e.g. polar: x = rcos θ, y = rsin θ gives |J| = r. Used in the chain rule for vector functions and in neural network backpropagation.

1.10

Hessian

H = [ fxx   fxy ;   fyx   fyy ]

Square matrix of second partials; symmetric when the second partials are continuous. It describes curvature and decides the nature of critical points.

1.11

Local maxima, minima and saddle points

  • Critical points: solve ∇f = 0.
  • Let D = fxx fyy − fxy2 at the point.
  • D > 0 and fxx > 0 → local minimum; D > 0 and fxx < 0 → local maximum.
  • D < 0 → saddle point; D = 0 → test fails.
  • In n variables: H positive definite → minimum, negative definite → maximum, indefinite → saddle.
1.12

Convex and concave functions

  • f is convex if H is positive semidefinite everywhere (e.g. all leading principal minors ≥ 0 and eigenvalues ≥ 0): a local minimum is then also the global minimum.
  • f is concave if H is negative semidefinite everywhere.
  • For two variables: convex if fxx ≥ 0 and D ≥ 0.

1.14

Gradient descent

xk+1 = xk − α ∇f(xk)
  • α is the learning rate: too small → slow; too large → overshoots or diverges.
  • Stops when |∇f| is small. Finds a local minimum; for convex f it is the global one.
  • To maximise, use gradient ascent (+α∇f).
  • Variants: batch, stochastic (one sample), mini-batch.

1.15

Introduction to tensors

components in n dimensions  nrank

A tensor generalises scalars, vectors and matrices to arrays with several indices. The rank (order) is the number of indices: scalar = rank 0, vector = rank 1, matrix = rank 2, a stack of matrices = rank 3.

  • Tensors are the data type of deep-learning libraries (TensorFlow, PyTorch).
  • Physical tensors (stress, inertia) transform in a fixed way under change of coordinates.
Q

Theory questions and model answers

Tap "Show model answer" to reveal.
Q1

Define gradient and state its geometric meaning.

Show model answer

∇f = (fx, fy, fz). It points in the direction of maximum increase of f, its magnitude is the maximum rate of change, and it is normal to the level surface f = c.

Q2

What is the directional derivative? Where is it maximum?

Show model answer

Du f = ∇f · u for a unit vector u. It is maximum, equal to |∇f|, along ∇f; minimum −|∇f| opposite; zero along the level curve.

Q3

Define divergence and curl. What do solenoidal and irrotational mean?

Show model answer

div F = ∂P/∂x + ∂Q/∂y + ∂R/∂z (net outflow); curl F = ∇ × F (rotation). Solenoidal: div F = 0. Irrotational: curl F = 0, so F = ∇φ for a scalar potential.

Q4

State the vector identities for curl grad, div curl and ∇ of r^n.

Show model answer

curl(grad f) = 0; div(curl F) = 0; ∇ · r = 3; ∇ × r = 0; ∇ rn = n rn−2 r; div(rn r) = (n + 3)rn; ∇2 rn = n(n + 1) rn−2.

Q5

Explain the Jacobian and the Hessian.

Show model answer

The Jacobian is the matrix of first partial derivatives of a vector function; its determinant scales volumes in a change of variables. The Hessian is the symmetric matrix of second partials describing curvature.

Q6

How do you classify critical points?

Show model answer

Solve ∇f = 0. With D = fxxfyy − fxy2: D > 0, fxx > 0 → minimum; D > 0, fxx < 0 → maximum; D < 0 → saddle; D = 0 inconclusive.

Q7

Explain Newton's method and gradient descent for optimisation.

Show model answer

Newton: xk+1 = xk − H−1∇f, quadratic convergence, needs the Hessian. Gradient descent: xk+1 = xk − α∇f, cheap steps, sensitive to the learning rate α.

P1

Gradient and unit normal

Find the gradient of φ = x² + y² + z² at (1, 2, 3) and the unit normal to the surface.

Show solution
  1. ∇φ = (2x, 2y, 2z).
  2. At (1, 2, 3): ∇φ = (2, 4, 6).
  3. |∇φ| = √(4 + 16 + 36) = √56 = 7.483.
Unit normal = (2, 4, 6)/√56 = (0.267, 0.535, 0.802).
P2

Directional derivative

Find the directional derivative of φ = xy² + yz³ at (2, −1, 1) in the direction (1, 2, 2).

Show solution
  1. ∇φ = (y², 2xy + z³, 3yz²).
  2. At (2, −1, 1): ∇φ = (1, -3, -3).
  3. Unit vector û = (1, 2, 2)/3.
  4. D = ∇φ · û = (1·1 + -3·2 + -3·2)/3 = -11/3.
Directional derivative = -11/3.
P3

Divergence and curl

For F = (x²y, y²z, z²x) find div F and curl F at (1, 1, 1).

Show solution
  1. div F = ∂(x²y)/∂x + ∂(y²z)/∂y + ∂(z²x)/∂z = 2xy + 2yz + 2zx = 6 at (1,1,1).
  2. curl F = (∂R/∂y − ∂Q/∂z, ∂P/∂z − ∂R/∂x, ∂Q/∂x − ∂P/∂y) = (−y², −z², −x²).
  3. At (1, 1, 1): curl F = (-1, -1, -1).
div F = 6 and curl F = (-1, -1, -1) at (1, 1, 1).
P4

Conservative field and potential

Show that F = (2xy + z³, x², 3xz²) is irrotational and find a scalar potential.

Show solution
  1. curl F = (∂(3xz²)/∂y − ∂(x²)/∂z, ∂(2xy + z³)/∂z − ∂(3xz²)/∂x, ∂(x²)/∂x − ∂(2xy + z³)/∂y) = (0, 0, 0).
  2. Since curl F = 0, F = ∇φ. Integrate F₁ w.r.t. x: φ = x²y + xz³ + g(y, z).
  3. Check: φ_y = x² ✓ and φ_z = 3xz² ✓, so g is constant.
φ = x²y + xz³ + C.
P5

Angle between two surfaces

Find the angle between the surfaces x² + y² + z² = 9 and z = x² + y² − 3 at (2, −1, 2).

Show solution
  1. n₁ = ∇(x² + y² + z² − 9) = (2x, 2y, 2z) = (4, -2, 4).
  2. n₂ = ∇(z − x² − y² + 3) = (−2x, −2y, 1) = (-4, 2, 1).
  3. n₁·n₂ = -16; |n₁| = 6.0; |n₂| = √21.
  4. cos θ = -0.5819.
θ = 54.4° (cos θ = 0.5819, so the surfaces are not orthogonal).
P6

Maxima, minima and saddle points

Find and classify the critical points of f = x³ + y³ − 3xy.

Show solution
  1. f_x = 3x² − 3y = 0 and f_y = 3y² − 3x = 0 → y = x² and x = y² → x⁴ = x → x = 0 or 1.
  2. Critical points: (0, 0) and (1, 1).
  3. H = [[6x, −3], [−3, 6y]], D = 36xy − 9.
  4. (0, 0): f_xx = 0, D = -9 → saddle point
  5. (1, 1): f_xx = 6, D = 27 → local minimum
Saddle point at (0, 0); local minimum at (1, 1) with f = −1.
P7

Jacobian

Find the Jacobian of the transformation x = r cos θ, y = r sin θ.

Show solution
  1. ∂x/∂r = cos θ, ∂x/∂θ = −r sin θ, ∂y/∂r = sin θ, ∂y/∂θ = r cos θ.
  2. J = cos θ · r cos θ − (−r sin θ)(sin θ) = r(cos²θ + sin²θ).
J = r, so dx dy = r dr dθ.
P8

Gradient descent

Minimise f = x² + 3y² starting at (3, 2) with learning rate 0.2. Perform 3 iterations.

Show solution
  1. ∇f = (2x, 6y).
  2. x₁ = (3 − 0.2·6, 2 − 0.2·12) = (1.80, -0.40).
  3. x₂ = (1.080, 0.080).
  4. x₃ = (0.6480, -0.0160).
The iterates (3.00, 2.00) → (1.80, -0.40) → … approach the minimum (0, 0); the y-component shrinks fast because its curvature is larger.
P9

Newton's method

Use Newton's method on f(x) = x³ − 2x − 5 starting at x₀ = 2 for three iterations.

Show solution
  1. f'(x) = 3x² − 2; x_{n+1} = x_n − f(x_n)/f'(x_n).
  2. x₁ = 2 − (−1)/10 = 2.1000.
  3. x₂ = 2.09457.
  4. x₃ = 2.094551.
Root ≈ 2.09455 (quadratic convergence: the digits roughly double each step).
P10

Convexity with the Hessian

Is f = x² + xy + y² convex?

Show solution
  1. f_xx = 2, f_yy = 2, f_xy = 1 → H = [[2, 1], [1, 2]].
  2. Leading principal minors: 2 > 0 and det H = 4 − 1 = 3 > 0, so H is positive definite.
Yes, f is (strictly) convex; its only critical point (0, 0) is the global minimum.
