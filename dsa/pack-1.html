Introduction

What a data structure is, and how we judge one.
1.1

Data structure

A data structure is a way of organising and storing data in memory so it can be accessed and modified efficiently. The choice of structure decides how fast the operations run.

1.2

Classification of data structures

ClassTypesExample
PrimitiveBuilt into the languageint, char, float, pointer
Non-primitive linearElements in a sequence, one after anotherArray, linked list, stack, queue
Non-primitive non-linearElements in a hierarchy or networkTree, graph
StaticSize fixed at compile timeArray
DynamicSize changes at run time, memory from the heapLinked list, dynamic stack / queue, tree
1.3

Abstract Data Type (ADT)

An ADT describes what operations a data type supports and what they do, not how they are implemented. Example: the Stack ADT defines push, pop, peek, isEmpty; it can be built on an array or on a linked list.

1.4

Static vs dynamic implementation

  • Static (array based): size fixed in advance, fast index access, possible wasted space or overflow, insert / delete in the middle needs shifting.
  • Dynamic (linked): grows and shrinks as needed, one extra pointer per node, no random access, insert / delete by pointer changes.
1.5

Time and space complexity

**Time complexity counts the basic steps as a function of input size n. Space complexity** counts the extra memory used. We study the growth rate for large n and ignore constants.

  • Best case — least work; worst case — most work; average case — expected work.
1.6

Asymptotic notation

Big O (upper bound)  f(n) = O(g(n))   if   f(n) ≤ c · g(n)   for all   n ≥ n0Ω (lower bound)  f(n) ≥ c · g(n)Θ (tight bound)  c1 g(n) ≤ f(n) ≤ c2 g(n)

Example: 3n2 + 2n + 5 = O(n2) with c = 4, n0 = 4. Drop constants and lower-order terms.

1.8

Applications of data structures

  • Array / list: tables, storage. Stack: undo, expression evaluation, recursion. Queue: scheduling, buffers, BFS.
  • Tree: file systems, expression trees, search trees, heaps. Graph: maps, social networks, networks routing.
  • Hash table: symbol tables, dictionaries, caches.

Theory questions and model answers

Q1

What is a data structure? How are data structures classified?

Show model answer

A data structure is a way of organising and storing data in memory so that it can be used efficiently.

Classification: primitive (int, char, float) and non-primitive; non-primitive splits into linear (array, linked list, stack, queue) and non-linear (tree, graph); also static (fixed size, array) and dynamic (size changes at run time, linked structures).

Q2

What is an Abstract Data Type (ADT)?

Show model answer

An ADT specifies what operations a data type provides and their behaviour, hiding how they are implemented. Example: the Stack ADT defines push, pop, peek, isEmpty; it can be built with an array or a linked list without changing user code.

Q3

Differentiate static and dynamic implementation of a data structure.

Show model answer

Static (array based): size fixed in advance, contiguous memory, O(1) index access, risk of overflow or wasted space, insertion in the middle needs shifting.

Dynamic (linked): nodes allocated at run time with pointers, size grows and shrinks, no random access, extra pointer memory, insertion by changing pointers.

Q4

Define time complexity and space complexity. What are best, worst and average cases?

Show model answer

Time complexity is the number of basic operations as a function of input size n; space complexity is the extra memory used. Best case is the least work for any input of size n, worst case the most, average case the expected work over all inputs. Worst case is the usual guarantee.

Q5

Define Big O, Omega and Theta notation.

Show model answer

f(n) = O(g(n)) if f(n) ≤ c g(n) for all n ≥ n0 (upper bound). f(n) = Ω(g(n)) if f(n) ≥ c g(n) (lower bound). f(n) = Θ(g(n)) if both hold (tight bound).

Q6

List some applications of data structures.

Show model answer
  • Arrays and lists: tables and storage; stack: undo, expression evaluation, recursion; queue: scheduling and buffering.
  • Trees: file systems, search structures, heaps; graphs: maps and networks; hash tables: symbol tables and caches.

P1

Big O proof

Show that f(n) = 3n2 + 2n + 5 is O(n2). Find c and n0.

Show solution
  1. We need c and n0 with 3n2 + 2n + 5 ≤ c n2 for all n ≥ n0.
  2. For n ≥ 1: 2n ≤ 2n2 and 5 ≤ 5n2, so f(n) ≤ 3n2 + 2n2 + 5n2 = 10n2.
  3. A tighter choice: for n ≥ 4, 2n + 5 ≤ n2 (at n = 4: 13 ≤ 16), so f(n) ≤ 4n2.
f(n) = O(n²) with c = 4 and n₀ = 4 (or c = 10 and n₀ = 1).
P2

Order the growth rates

Arrange in increasing order of growth: n2, 2n, n log n, n, log n, n!, 1.

Show solution
  1. Constants beat everything slowest: 1.
  2. Then logarithmic: log n; then linear: n; then n log n; then polynomial n²; then exponential 2ⁿ; then factorial n!.
1 < log n < n < n log n < n² < 2ⁿ < n!.
P3

Loop analysis

Find the time complexity of: for (i = 1; i < n; i = i * 2) { for (j = 0; j < n; j++) { ... } }

Show solution
  1. The outer variable doubles each time (1, 2, 4, …), so it runs ⌈log₂ n⌉ times.
  2. The inner loop always runs n times.
  3. Total = n · log₂ n basic steps.
T(n) = O(n log n).
P4

Recursive space

What are the time and space complexities of the recursive function factorial(n) = n · factorial(n − 1), factorial(0) = 1?

Show solution
  1. There is one call per value n, n − 1, …, 0, so n + 1 calls, each doing O(1) work: time O(n).
  2. Every pending call stays on the system stack until the base case returns, so the stack holds n + 1 frames: space O(n).
Time O(n), space O(n); an iterative loop needs only O(1) space.
P5

Count operations

How many times does the statement run? for (i = 0; i < n; i++) for (j = i; j < n; j++) x++;

Show solution
  1. For i = 0 the inner loop runs n times, for i = 1 it runs n − 1 times, …, for i = n − 1 it runs once.
  2. Total = n + (n − 1) + … + 1 = n(n + 1)/2.
n(n + 1)/2 times, so O(n²).
