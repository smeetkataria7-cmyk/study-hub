Linked lists

Nodes joined by pointers; grow and shrink at run time.
2.1

Dynamic memory allocation

p = (type *)malloc(n * sizeof(type));p = (type *)calloc(n, sizeof(type));p = (type *)realloc(p, new_size); free(p);

malloc reserves bytes (uninitialised), calloc reserves and zero-fills, realloc resizes, free releases. Memory comes from the heap and must be freed to avoid leaks.

2.5

Insertion and deletion by pointer changes

  • Insert after node t: p->next = t->next; t->next = p.
  • Delete node after t: d = t->next; t->next = d->next; free(d).
  • DLL insert after t: p->next = t->next; p->prev = t; t->next->prev = p; t->next = p.
  • Always set the new node's pointers before changing existing ones, or the rest of the list is lost.
2.6

Application: polynomial representation and addition

Each node holds a coefficient and an exponent, kept in decreasing exponent order. To add two polynomials walk both lists together:

  • Higher exponent first: copy that term and advance that list.
  • Equal exponents: add the coefficients (skip the term if the sum is 0) and advance both.
  • Copy whatever remains of either list.
2.7

J(1) = 0,   J(n) = (J(n − 1) + k) mod n

n people in a circle, every k-th is eliminated; a circular linked list models it. The recurrence gives the survivor's 0-based position (add 1 for numbering from 1).

3

Stack

Last in, first out: expressions and recursion live here.
3.1

Stack as an ADT

A stack allows insertion and deletion at one end only, the top: LIFO (last in, first out).

  • push(x) — insert at top; pop() — remove and return the top; peek() — read the top.
  • isEmpty, isFull.
3.2

Array representation

empty  top = −1full  top = MAX − 1push  stack[++top] = xpop  x = stack[top−−]

Pushing onto a full stack is overflow; popping from an empty stack is underflow. All operations are O(1).

3.3

Linked representation

The head of the list is the top: push = insert at beginning, pop = delete from beginning. No overflow (until memory runs out), still O(1).

3.4

3.6

Infix to postfix: algorithm

  • Scan left to right. Operand → output.
  • ( → push. ) → pop to output until (, then discard (.
  • Operator → pop to output while the top has higher precedence (or equal, if the operator is left associative), then push it.
  • At the end pop everything to the output.
  • For prefix: reverse the infix string, swap ( and ), convert as above using the strict rule for equal precedence, then reverse the result.

Evaluating postfix and prefix

  • Postfix: scan left to right; push operands; on an operator pop b then a, push a op b.
  • Prefix: scan right to left; on an operator pop a then b, push a op b.

Queue

First in, first out, with its circular, priority and double-ended forms.
4.1

Queue as an ADT

A queue inserts at the rear and deletes at the front: FIFO (first in, first out).

  • enqueue(x), dequeue(), front / peek, isEmpty, isFull.
4.2

Array representation

empty  front = −1full  rear = MAX − 1enqueue  q[++rear] = xdequeue  x = q[front++]

Drawback: after dequeues the slots before front are wasted, so the queue can say "full" while empty space remains. The circular queue fixes this.

4.3

Linked representation

Keep front and rear pointers: enqueue at rear (O(1)), dequeue at front (O(1)). When the last node is removed set both pointers to NULL.

4.4

Circular queue

enqueue  rear = (rear + 1) mod MAXdequeue  front = (front + 1) mod MAXfull  (rear + 1) mod MAX = frontempty  front = −1

Indexes wrap to 0 after MAX − 1, so freed slots are reused. With this full test one slot may stay unused, or keep a count.

4.5

Priority queue

Each item has a priority; the highest-priority item leaves first, whatever its arrival order (ties: FIFO).

  • Ordered list: insert in priority order (O(n)), delete the head (O(1)).
  • Unordered list: insert O(1), delete O(n) (search for the highest).
  • Heap: insert and delete both O(log n).
4.6

Double-ended queue (deque)

  • Insertion and deletion at both ends.
  • Input-restricted: insert at one end only, delete at both.
  • Output-restricted: delete at one end only, insert at both.
  • A deque can work as a stack or as a queue.
4.7

Applications of queues

  • CPU and disk scheduling, printer spooling, buffers (keyboard, network).
  • Breadth-first search, level-order tree traversal.
  • Call-centre and ticket systems; priority queues for operating systems and Dijkstra.

Q

Theory questions and model answers

Tap "Show model answer" to reveal.
Q1

Differentiate between an array and a linked list.

Show model answer

Array: fixed size, contiguous, O(1) random access, insert / delete O(n) because of shifting, no extra pointer space. Linked list: dynamic size, scattered nodes joined by pointers, O(n) access, O(1) insert / delete once the position is known, extra memory for pointers.

Q2

Explain the types of linked list.

Show model answer
  • Singly: each node has data and next; one-way.
  • Doubly: prev and next; two-way traversal, easier deletion.
  • Circular: the last node points to the first; no NULL.
  • Doubly circular: both: next and prev links wrap round.
Q3

Explain the stack ADT and list its applications.

Show model answer

A stack is a LIFO structure with insertion and deletion at one end, the top: push, pop, peek, isEmpty, isFull. Overflow = push on a full stack; underflow = pop on an empty one.

Applications: expression conversion and evaluation (Polish notation), function calls and recursion, undo, balanced-bracket checking, depth-first search.

Q4

Explain infix to postfix conversion with the algorithm.

Show model answer
  • Scan left to right; operands go straight to the output.
  • "(" is pushed; ")" pops to the output until "(" (discarded).
  • An operator pops operators of higher (or equal, when left associative) precedence, then is pushed; "^" is right associative.
  • At the end pop everything to the output.
Q5

Why is a circular queue better than a linear queue?

Show model answer

In a linear array queue, slots freed by dequeues before front are never reused, so the queue reports "full" while space remains. A circular queue wraps the indexes with (i + 1) mod MAX, reusing freed slots. It is full when (rear + 1) mod MAX = front.

Q6

Describe priority queue and deque.

Show model answer

A priority queue removes the item of highest priority first (ordered list: insert O(n), delete O(1); heap: both O(log n)). A deque allows insertion and deletion at both ends; input-restricted and output-restricted forms limit one side.

Q7

Explain recursion with an example.

Show model answer

A function that calls itself on a smaller problem until a base case stops it. Each call is pushed on the system stack. Example: n! = n · (n − 1)! with 0! = 1. Tower of Hanoi needs 2n − 1 moves.

P4

Circular queue trace

MAX = 5. Perform: enqueue 10, 20, 30, 40; dequeue twice; enqueue 50, 60, 70. Trace front and rear.

Show solution
  1. enqueue 10: rear = 0, front = 0
  2. enqueue 20: rear = 1, front = 0
  3. enqueue 30: rear = 2, front = 0
  4. enqueue 40: rear = 3, front = 0
  5. dequeue → 10: front = 1, rear = 3
  6. dequeue → 20: front = 2, rear = 3
  7. enqueue 50: rear = 4, front = 2
  8. enqueue 60: rear = 0, front = 2
  9. enqueue 70: rear = 1, front = 2
Final array (index 0–4): 60 70 30 40 50 — wrap-around reuses the two freed slots, and the queue is now full.
P5

Josephus problem

Seven people stand in a circle and every 3rd person is eliminated. Who survives?

Show solution
  1. Count 3 from person 1 each time, removing the third and continuing from the next person.
  2. Elimination order: 3, 6, 2, 7, 5, 1.
Survivor: person 4.
P6

Polynomial addition

Add 5x3 + 4x2 + 2x + 7 and 3x3 + x2 + 6 using linked lists.

Show solution
  1. Lists (coef, exp): (5,3)→(4,2)→(2,1)→(7,0) and (3,3)→(1,2)→(6,0).
  2. Exponent 3: 5 + 3 = 8. Exponent 2: 4 + 1 = 5. Exponent 1 only in the first: 2. Exponent 0: 7 + 6 = 13.
Sum = 8x³ + 5x² + 2x + 13.
P7

Reverse a singly linked list

Show how prev, curr and next move when reversing 1 → 2 → 3 → NULL.

Show solution
  1. Start prev = NULL, curr = 1.
  2. Node 1: next = 2; 1.next = NULL; prev = 1; curr = 2.
  3. Node 2: next = 3; 2.next = 1; prev = 2; curr = 3.
  4. Node 3: next = NULL; 3.next = 2; prev = 3; curr = NULL; stop and set head = prev.
Reversed list: 3 → 2 → 1 → NULL.
