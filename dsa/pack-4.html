7

Set, Map & Dictionary

Abstract collections and the structures that implement them.
7.1

Set ADT

An unordered collection of distinct elements. Operations: add, remove, contains, union, intersection, difference, size. Implemented with arrays, sorted lists, bit vectors or hash tables.

7.2

Partitions with union–find

  • A partition splits elements into disjoint sets, each a tree whose root is the representative.
  • make_set(x) — new set {x}. find(x) — return the root. union(a, b) — join the two sets.
  • Path compression (point nodes straight at the root) and union by rank (attach the shorter tree under the taller) make operations almost O(1) (amortised α(n)).
  • Use: connected components, Kruskal's minimum spanning tree.
7.3

Map ADT

A collection of (key, value) pairs with unique keys. Operations: put(key, value), get(key), remove(key), containsKey. Example: student roll number → name.

7.4

Dictionary ADT

Like a map, but keys may be unordered or ordered, and duplicates may be allowed (multimap). Common implementations:

  • Unordered list: search O(n).
  • Sorted array: search O(log n), insert O(n).
  • Hash table: search, insert, delete O(1) average.
  • Balanced BST: all operations O(log n), keeps keys sorted.
7.5

Applications

  • Sets: removing duplicates, membership tests, relational operations.
  • Maps and dictionaries: symbol tables, word counts, caches, database indexes, phone books.

Q1

What is the Set ADT? List its operations and implementations.

Show model answer

A set is an unordered collection of distinct elements with operations add, remove, contains, union, intersection, difference and size. Implementations: arrays, sorted lists, bit vectors and hash tables.

Q2

Explain partitions with union–find.

Show model answer

A partition splits the elements into disjoint sets, each represented by a tree whose root is the set leader. find(x) returns the root, union(a, b) joins the roots. Path compression and union by rank make operations almost O(1).

Q3

What is a Map ADT?

Show model answer

A collection of (key, value) pairs with unique keys; operations put, get, remove and containsKey. Example: roll number → name.

Q4

Explain the Dictionary ADT and its implementations.

Show model answer

A dictionary stores (key, value) entries and supports insert, search and delete. Implementations: unordered list O(n), sorted array (search O(log n), insert O(n)), hash table O(1) average, balanced BST O(log n) with sorted order.

Q5

Give applications of sets, maps and dictionaries.

Show model answer
  • Sets: duplicate removal, membership tests, relational operations.
  • Maps and dictionaries: symbol tables, word counts, caches, database indexes, phone books.
  • Union–find: connected components and Kruskal's algorithm.

P1

Union–find trace

Elements 1–6 start in singleton sets. Perform union(1,2), union(3,4), union(1,3), union(5,6), union(4,6) using union by rank and give the parent array after each step.

Show solution
  1. Start: parent[1..6] = 1 2 3 4 5 6.
  2. union(1, 2): parent[1..6] = 1 1 3 4 5 6
  3. union(3, 4): parent[1..6] = 1 1 3 3 5 6
  4. union(1, 3): parent[1..6] = 1 1 1 3 5 6
  5. union(5, 6): parent[1..6] = 1 1 1 3 5 5
  6. union(4, 6): parent[1..6] = 1 1 1 1 1 5
  7. find(2) = 1.
All six elements end in one set with root 1; find(2) = 1.
P2

Set operations

A = {1, 3, 5, 7}, B = {3, 4, 5, 6}. Find A ∪ B, A ∩ B, A − B and B − A.

Show solution
  1. Union: all distinct elements of both.
  2. Intersection: elements in both: 3, 5.
  3. A − B: elements of A not in B: 1, 7.
  4. B − A: 4, 6.
A ∪ B = {1, 3, 4, 5, 6, 7}; A ∩ B = {3, 5}; A − B = {1, 7}; B − A = {4, 6}.
P3

Dictionary with chaining

Use h(word) = (sum of ASCII codes) mod 5 and separate chaining. Insert cat, dog, bat, ant and show the table.

Show solution
  1. ASCII sums: cat = 312, dog = 314, bat = 311, ant = 323.
  2. Indexes mod 5: cat 2, dog 4, bat 1, ant 3.
  3. Bucket 0: (empty)
  4. Bucket 1: bat
  5. Bucket 2: cat
  6. Bucket 3: ant
  7. Bucket 4: dog
Table: 0: –; 1: bat; 2: cat; 3: ant; 4: dog.
P4

Map operations

Starting with an empty map perform put(3, A), put(5, B), put(3, C), get(3), remove(5), get(5).

Show solution
  1. put(3, A): {3: A}. put(5, B): {3: A, 5: B}.
  2. put(3, C): key 3 exists, so its value is updated: {3: C, 5: B}.
  3. get(3) returns C.
  4. remove(5): {3: C}.
  5. get(5) returns "not found".
Final map {3: C}; get(3) = C; get(5) = absent.
