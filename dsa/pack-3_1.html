Trees

Hierarchies: binary trees, BST, threaded trees and AVL trees.

5.2

Types of binary tree

TypeDefinition
Binary treeEvery node has at most 2 children (left, right)
Full (strict)Every node has 0 or 2 children
CompleteAll levels full except possibly the last, filled from the left
PerfectAll internal nodes have 2 children and all leaves are on one level
SkewedEvery node has one child only (like a linked list)

5.3

Properties of binary trees

max nodes at level i  2i − 1max nodes, height h  2h − 1min height, n nodes  ⌈ log2(n + 1) ⌉edges  n − 1leaves  n0 = n2 + 1

Levels start at 1 and height counts nodes. n2 is the number of nodes with two children, n0 the number of leaves.

5.4

Array representation of a binary tree

node at index i  left  2i + 1 ,   right  2i + 2 ,   parent  ⌊(i − 1)/2⌋

Zero-based indexes. Efficient for complete trees (heaps); wasteful for skewed trees. Linked representation uses left and right pointers.

5.5

Binary tree traversals

  • Inorder: Left, Root, Right.
  • Preorder: Root, Left, Right.
  • Postorder: Left, Right, Root.
  • Level order: level by level using a queue.
  • Inorder of a BST visits the keys in ascending order. Preorder + inorder (or postorder + inorder) uniquely determine a tree; preorder + postorder does not.

5.6

Binary search tree operations

search / insert / delete  O(h) ,   h = height
  • Search: go left if key < node, right if greater.
  • Insert: search for the key; attach the new leaf where the search ends.
  • Minimum: leftmost node. Maximum: rightmost node.
  • Delete: leaf → remove; one child → replace by the child; two children → copy the inorder successor (smallest of the right subtree) into the node, then delete the successor.
  • Balanced: h = log n. Skewed (sorted input): h = n, so the operations become O(n).
5.7

Threaded binary tree

A normal tree has many NULL pointers (n + 1 of them). A threaded tree replaces them with pointers to the inorder predecessor or successor, so inorder traversal needs no stack and no recursion. A flag marks whether a pointer is a real child or a thread. Types: single (right) threaded and double threaded.

5.8

AVL tree

balance factor = height(left) − height(right) ∈ {−1, 0, +1}

A self-balancing BST. After an insert or delete, rebalance by rotations so search, insert and delete stay O(log n).

CaseImbalanceFix
Left-Left (LL)Inserted in left subtree of left childSingle right rotation
Right-Right (RR)Inserted in right subtree of right childSingle left rotation
Left-Right (LR)Inserted in right subtree of left childLeft rotation at the child, then right rotation at the node
Right-Left (RL)Inserted in left subtree of right childRight rotation at the child, then left rotation at the node
5.9

AVL height bound

N(h) = N(h − 1) + N(h − 2) + 1h < 1.44 log2(n + 2)

N(h) is the minimum number of nodes in an AVL tree of height h (N(0) = 0, N(1) = 1), which grows like Fibonacci numbers.

5.10

Applications of trees

  • File systems and directories, XML / HTML (DOM), organisation charts.
  • Expression trees (parsing), decision trees, Huffman coding.
  • BST / AVL for ordered search, heaps for priority queues, tries for dictionaries and autocomplete.
  • Self-learning: red-black, trie, suffix, splay, B and B+ trees.

6.2

Handshake rule

Σ deg(v) = 2|E|

Sum of all degrees is twice the number of edges (undirected graph), so the number of odd-degree vertices is even.

6.3

Representation

BasisAdjacency matrixAdjacency list
SpaceO(V²)O(V + E)
Edge test (u, v)O(1)O(degree)
List all neighboursO(V)O(degree)
Best forDense graphsSparse graphs

Matrix entry is 1 (or the weight) if an edge exists. For an undirected graph the matrix is symmetric.

6.4

Depth First Search (DFS)

  • Visit a vertex, mark it, then recursively visit an unvisited neighbour; backtrack when none is left.
  • Uses a stack (or recursion). Time O(V + E) with a list, O(V²) with a matrix.
  • Uses: cycle detection, topological sort, connected components, maze solving.
6.5

Breadth First Search (BFS)

  • Visit the start vertex, then all its neighbours, then their neighbours, level by level.
  • Uses a queue; mark a vertex when it is enqueued. Time O(V + E) with a list, O(V²) with a matrix.
  • Uses: shortest path in an unweighted graph, level order, web crawling, broadcasting.

6.6

Applications of graphs

  • Road maps and shortest routes, computer and social networks, web links.
  • Scheduling with dependencies (topological order), circuit design, molecules.
Q

Theory questions and model answers

Tap "Show model answer" to reveal.
Q1

Define the basic tree terms: root, leaf, height, level, degree.

Show model answer

Root: the top node. Leaf: a node with no children. Level: distance from the root (root at 1). Height: length (in nodes or edges) of the longest root-to-leaf path. Degree: number of children of a node (of a tree: the maximum).

Q2

State the properties of a binary search tree and its search cost.

Show model answer

For every node, all keys in the left subtree are smaller and all keys in the right subtree larger. Search, insert and delete cost O(h): O(log n) when balanced, O(n) for a skewed tree.

Q3

Explain the binary tree traversals.

Show model answer
  • Inorder: left, root, right (sorted order for a BST).
  • Preorder: root, left, right. Postorder: left, right, root.
  • Level order: level by level with a queue.
Q4

Explain the deletion of a node from a BST.

Show model answer
  • Leaf: remove it.
  • One child: replace the node by its child.
  • Two children: copy the inorder successor (smallest of the right subtree) into the node and delete the successor.
Q5

What is a threaded binary tree and why is it used?

Show model answer

NULL pointers are replaced by threads to the inorder predecessor or successor. Inorder traversal then needs no stack or recursion, and the n + 1 wasted NULL pointers are put to use.

Q6

What is an AVL tree? Explain the rotations.

Show model answer

A BST in which every node has balance factor height(left) − height(right) in {−1, 0, +1}. LL → right rotation; RR → left rotation; LR → left rotation at the child then right at the node; RL → right then left. All operations are O(log n).

Q7

Compare DFS and BFS.

Show model answer

DFS uses a stack (or recursion) and goes deep before backtracking; BFS uses a queue and visits level by level, giving shortest paths in unweighted graphs. Both are O(V + E) with adjacency lists.

Practice problems with solutions

P1

BST construction and traversals

Insert 45, 15, 79, 90, 10, 55, 12, 20, 50 into an empty BST and give the three traversals and the height.

Show solution
  1. Insert in order: 45 is the root; 15 < 45 left; 79 > 45 right; 90 right of 79; 10 left of 15; 55 left of 79; 12 right of 10; 20 right of 15; 50 left of 55.
  2. Tree: 45(15(10(-, 12), 20), 79(55(50, -), 90)).
  3. Inorder: 10 12 15 20 45 50 55 79 90.
  4. Preorder: 45 15 10 12 20 79 55 50 90.
  5. Postorder: 12 10 20 15 50 55 90 79 45.
Height = 4 levels. Inorder is sorted, as expected for a BST.
P2

BST deletion

In the BST built from 50, 30, 70, 20, 40, 60, 80 delete 20, then 30, then 50.

Show solution
  1. Start: 50(30(20, 40), 70(60, 80)).
  2. Delete 20 (leaf) → 50(30(-, 40), 70(60, 80))
  3. Delete 30 (one child) → 50(40, 70(60, 80))
  4. Delete 50 (two children) → 60(40, 70(-, 80))
Final tree: 60(40, 70(-, 80)) (the inorder successor of 50 was 60).
P3

AVL insertion

Insert 10, 20, 30, 40, 50, 25 into an AVL tree and show the rotations.

Show solution
  1. inserting 30: node 10 has balance factor −2 (RR) → left rotation
  2. inserting 50: node 30 has balance factor −2 (RR) → left rotation
  3. inserting 25: node 20 has balance factor −2 (RL) → right rotation at 40, then left rotation at 20
  4. Final tree (root first): 30(20(10, 25), 40(-, 50))
AVL tree: 30(20(10, 25), 40(-, 50)).
P4

Construct a tree from traversals

Inorder: D B E A F C. Preorder: A B D E C F. Construct the tree and give the postorder.

Show solution
  1. The first preorder item A is the root.
  2. In the inorder sequence, D B E lie left of A and F C right of A.
  3. Left subtree: preorder B D E, inorder D B E → root B with children D and E.
  4. Right subtree: preorder C F, inorder F C → root C with left child F.
Tree: A(B(D, E), C(F, –)); postorder: D E B F C A.
P5

DFS and BFS

Graph with edges 0–1, 0–2, 1–3, 1–4, 2–4, 3–5, 4–5. Give DFS and BFS from vertex 0, visiting smaller vertices first.

Show solution
  1. Adjacency: 0: 1 2; 1: 0 3 4; 2: 0 4; 3: 1 5; 4: 1 2 5; 5: 3 4.
  2. DFS: go deep: 0 1 3 5 4 2.
  3. BFS: level by level: 0 1 2 3 4 5.
DFS: 0 1 3 5 4 2; BFS: 0 1 2 3 4 5.
P6

Binary tree counts

A complete binary tree has height 4 (4 levels, root at level 1). Find the maximum number of nodes and of leaves.

Show solution
  1. Maximum nodes = 2⁴ − 1 = 15.
  2. Leaves at level 4 = 2^(4−1) = 8.
  3. Check: leaves = internal nodes + 1 = 7 + 1.
15 nodes and 8 leaves.
