4.1

What a set is

A set is a collection that contains no duplicates. The three basic operations are union (S1 ∪ S2: everything in either set), intersection (S1 ∩ S2: only elements in both) and difference (S1 − S2: elements of S1 that are not in S2).

The slides stress that a set allows operations on a collection of elements in an efficient and organised way, and that sets are the base for the partitioning problem (union-find) later in the unit.

  • Example: S1 = {1, 3, 5, 7}, S2 = {3, 4, 5, 6}. S1 ∪ S2 = {1, 3, 4, 5, 6, 7}; S1 ∩ S2 = {3, 5}; S1 − S2 = {1, 7}; S2 − S1 = {4, 6}.
  • Order and repetition do not matter: {1, 2, 3} = {3, 2, 1} = {1, 1, 2, 3}.

Sets A1 and A2 are disjoint partitions of A if and only if both conditions hold: A1 ∪ A2 = A (together they cover A) and A1 ∩ A2 = Φ (they share no element).

4.6

Union-find in C (teacher style)

The array Arr stores the parent of every element; a root is its own parent.

int arr[10];

void init(void)
{
    int i;
    for (i = 0; i < 10; i++)
        arr[i] = i;          /* every element is its own set */
}

int root(int i)
{
    while (arr[i] != i)
        i = arr[i];          /* climb to the set leader */
    return i;
}

void unionset(int a, int b)   /* a = child, b = parent */
{
    int ra = root(a), rb = root(b);
    arr[ra] = rb;
}

int find(int a, int b)        /* connected? */
{
    return root(a) == root(b);
}

Cost: with this simple version, root() can take O(n) in the worst case (a long chain), so find and union are O(n). Two standard improvements: union by rank/size (attach the shorter tree under the taller) and path compression (point every node on the search path directly at the root); together they make the operations almost O(1) amortised.

4.7

Applications of set partitioning

  • Elections (grouping voters or results), classification, pattern matching.
  • Divide and conquer (splitting a problem into disjoint parts).
  • Mutually exclusive processes in an operating system.
  • Combinatorial explosion problems where repetition is not allowed.
  • In general: algorithms, data analysis and databases. The main advantage of the set data structure is that operations on a collection of elements are efficient and organised.
4.8

What a map is

A map (also called a table, search table, associative array or associative container) is a data structure optimised for one specific kind of search or access. A bag is accessed by asking "is X present?", a list by "give me item number X", a queue by "give me the item that has been in the collection the longest". In a map we ask: "give me the value associated with this key."

A map models a searchable collection of key-value entries. It stores pairs (k, v), called entries. Each key is unique (it acts as an identifier or "address" for the value), so the association of keys to values defines a mapping. Multiple entries with the same key are not allowed; a map cannot contain duplicate keys.

  • Operations: searching, inserting and deleting items.
  • Applications: address book, student-record database (the key is the student ID; two students cannot share an ID), look-up situations such as student ID → last name, or house number → number of pets.
  • Unlike an array, whose index must be an integer, a map index (key) can be nearly any scalar type: a character array, a real number, a signed or unsigned integer. The values can be of any type: numeric arrays, structures, cells, character arrays, objects or other maps.
  • Example from the slides: mean monthly rainfall, with the month as key and rainfall in mm as value (key "August" gives 37.3).
4.9

Map ADT

Value definition: a map is a collection of key-value entries, each value associated with a distinct key. Assumption: the map provides a special pointer-like object, the iterator (position), that references entries and lets us navigate around the map. Given an iterator p, the entry is obtained by dereferencing, *p, and the key and value are read with p->key() and p->value().

  • Standard operations: find(k) (search by key), put(k, v) (insert or replace), erase(k) / erase(p) (remove), size(), empty(), begin() and end().
  • The slides define a map as any data structure that groups a dynamic number of key-value pairs: it lets us retrieve values by key, insert new key-value pairs and update the values associated with keys.

4.13

What a dictionary is

A dictionary allows the keys and the values to be of any object type. Unlike a map, a dictionary allows multiple entries with the same key. Example: an English dictionary, where one word can have several definitions. Others from the slides: records of computer-science authors indexed by first and last names; a multi-user computer game that needs a mapping from rooms to players (many players can be in one room).

The Dictionary ADT therefore supports find(k) (one entry with key k), findAll(k) (all entries with key k), insert(k, v), erase(entry) and size / empty; because keys can repeat, erase takes an entry (position), not just a key.

Dictionary operations in C++

Using a phone book (slides 68 to 72).

std::map<std::string, std::string> phoneBook;
phoneBook["Alice"] = "123-456-7890";            // add
phoneBook["Bob"]   = "987-654-3210";
phoneBook.insert(std::make_pair("Charlie", "555-123-4567"));

std::string aliceNumber = phoneBook["Alice"];     // access by key

if (phoneBook.find("Bob") != phoneBook.end())     // find()
    std::string bobNumber = phoneBook["Bob"];

phoneBook.erase("Alice");                         // remove
if (phoneBook.count("Bob") > 0) { ... }          // count()
// ordered dictionary allowing duplicate keys
std::multimap<std::string, int> d;
d.insert(std::make_pair("apple", 5));
d.insert(std::make_pair("banana", 3));
d.insert(std::make_pair("cherry", 7));
d.insert(std::make_pair("banana", 8));   // duplicate key allowed

In a multimap duplicate keys are allowed, so banana appears twice. Both the ordered and unordered multimaps need no extra code to store several values per key.

Q1

What is a set? Explain the basic set operations with an example.

Show model answer

A set is a collection that contains no duplicates. The basic operations are union S1 ∪ S2, intersection S1 ∩ S2 and difference S1 − S2.

  • S1 = {1, 3, 5, 7}, S2 = {3, 4, 5, 6}.
  • S1 ∪ S2 = {1, 3, 4, 5, 6, 7}; S1 ∩ S2 = {3, 5}; S1 − S2 = {1, 7}.
  • The Set ADT also provides add, remove, contains (membership), size and empty.
Q2

List and explain the main functions of the set container in the C++ STL.

Show model answer
  • Iterators: begin(), end(), rbegin(), rend() and the constant versions cbegin(), cend(), crbegin(), crend().
  • Capacity: size(), max_size(), empty().
  • Modifiers: insert(g), erase(position) / erase(g), clear(), emplace(), emplace_hint(), swap().
  • Operations: find(g) (iterator or end()), count(g) (1 or 0), lower_bound(g), upper_bound(g), equal_range().
  • Observers: key_comp(), value_comp(); the default order is "<".
Q3

What are disjoint sets and partitions? Give an example.

Show model answer

Sets A1 and A2 are disjoint partitions of A iff A1 ∪ A2 = A and A1 ∩ A2 = Φ. For A = {1, 2, 3, 4, 5, 6, 7}: A1 = {1, 2, 3, 4, 5} and A3 = {6, 7} are disjoint partitions (union = A, intersection empty), but A1 and A2 = {2, 4, 6} are not (intersection {2, 4} is not empty and 7 is missing).

Q4

Explain set partitioning using the union-find operations with an example.

Show model answer

Union creates disjoint subsets by merging two subsets; Find checks connectivity (whether two elements are in the same subset). Keep an array Arr in which Arr[i] is the parent of i; initially Arr[i] = i (each element is its own subset). Union(a, b) makes the root of a a child of the root of b; Find(a, b) is true when both have the same root.

  1. S = {0, …, 9}: ten singleton subsets.
  2. Union(2,1), Union(4,3), Union(8,4), Union(9,3), Union(6,5) → components {0}, {1,2}, {3,4,8,9}, {5,6}, {7}.
  3. Union(5,2) merges {1,2} and {5,6} → {0}, {1,2,5,6}, {3,4,8,9}, {7}.
  4. Find(6,1) = True, Find(8,9) = True, Find(7,1) = False.
Four subsets remain; the elements of each are said to be connected components.

Q6

What is a Map? Explain the Map ADT.

Show model answer

A map (table, search table, associative array, associative container) stores key-value entries; keys are unique and each key identifies (is the "address" of) its value. Accessing a map means asking for the value associated with a key. Multiple entries with the same key are not allowed.

  • Operations: find / get(k), put(k, v) (insert or update), erase(k), size, empty, begin, end.
  • An iterator (position) references entries; for iterator p, *p is the entry, p->key() and p->value() give its parts.
  • Applications: address book, student-record database (student ID as key).
Q7

Explain any five map functions of the C++ STL with syntax and an example.

Show model answer
  • begin(): mapname.begin(); iterator to the first element.
  • end(): mapname.end(); iterator past the last element (not dereferenceable).
  • insert(): map_name.insert({key, element}); not inserted if the key exists. mp.insert({2, 30}) then mp.insert({2, 20}) keeps 2 → 30.
  • size(): map_name.size(); {1:India, 2:Nepal, 3:Sri Lanka, 4:Myanmar}.size() = 4, empty map gives 0.
  • clear() removes all elements (size becomes 0); erase(key) returns 1 if found else 0; empty() returns true if there are no elements.
Q8

Explain the different ways of implementing a map.

Show model answer
  • Unsorted (doubly) linked list or array of pairs: every operation O(n); simple but slow.
  • Hash table: about O(1) average; needs a good hash function; keys unordered.
  • Binary search tree: O(log n); keys in sorted order.
  • Skip list: expected O(log n).
Q9

What is a dictionary? How does it differ from a map?

Show model answer

A dictionary stores key-value entries where keys and values can be of any object type, and — unlike a map — several entries may have the same key. Example: a word with many meanings. A map allows only one value per key.

  • C++: map / unordered_map for unique keys; multimap / unordered_multimap for duplicate keys.
  • ADT operations: find(k), findAll(k), insert(k, v), erase(entry).
Q10

Compare std::map and std::unordered_map.

Show model answer

Both store key-value pairs. std::map is a sorted associative container built on a red-black tree: O(log n) search, insert and delete, keys in sorted order. std::unordered_map is hash based: O(1) average time (O(n) worst case), no ordering, needs a good hash function.

Q11

Distinguish between set, map and dictionary.

Show model answer

A set holds single elements with no duplicates. A map holds key-value pairs with unique keys. A dictionary holds key-value pairs where keys may repeat. In C++: set, map and multimap respectively (with unordered_ versions for hashing).

Q12

Describe dictionary implementations using an unordered list and a hash table with separate chaining.

Show model answer
  • Unordered list: entries kept in a linked list L; each entry stores a location variable pointing to its own position in L, so erasing a known entry is O(1); search is O(n).
  • Hash table with separate chaining: bucket array A and hash function h; entry (k, v) goes into the list A[h(k)]; the location variable points to the entry inside that bucket list. Search, insert and erase are O(1) on average with a low load factor.

  8. After step 5 the subsets are {0}, {1,2}, {3,4,8,9}, {5,6}, {7} (5 subsets); after step 6 they are {0}, {1,2,5,6}, {3,4,8,9}, {7} (4 subsets).

  10. Find(8,9): root(8) = 3, root(9) = 3 → True.
  11. Find(7,1): root(7) = 7, root(1) = 1 → False.
Final Arr = 0 1 1 3 3 1 5 7 3 3; Find(6,1) = True, Find(8,9) = True, Find(7,1) = False.
P4

Map operations

Starting with an empty map perform insert({2,30}), insert({1,40}), insert({3,60}), insert({2,20}), insert({5,50}), then erase(1), erase(2), size(), empty(). Give the contents after each stage.

Show solution
  1. After the first three inserts: {1:40, 2:30, 3:60} (printed in key order).
  2. insert({2,20}): key 2 already exists, so the map is unchanged. insert({5,50}) → {1:40, 2:30, 3:60, 5:50}.
  3. erase(1) returns 1 → {2:30, 3:60, 5:50}. erase(2) returns 1 → {3:60, 5:50}.
  4. size() = 2; empty() = false.
Final map {3:60, 5:50}; size 2; not empty (matches the slide "before / after erase" output).
P5

Map ADT calls

Starting with an empty map perform put(3, A), put(5, B), put(3, C), get(3), erase(5), get(5).

Show solution
  1. put(3, A): {3:A}. put(5, B): {3:A, 5:B}.
  2. put(3, C): key 3 already present, so with put the value is replaced: {3:C, 5:B}. (With the STL insert() the old value would stay.)
  3. get(3) returns C. erase(5) → {3:C}. get(5): not found.
Final {3:C}; get(3) = C; get(5) = not found.
P6

Dictionary with chaining

Use h(word) = (sum of ASCII codes) mod 5 and separate chaining. Insert cat, dog, bat, ant and draw the table.

Show solution
  1. ASCII sums: cat = 312, dog = 314, bat = 311, ant = 323.
  2. Indexes (mod 5): cat → 2, dog → 4, bat → 1, ant → 3.
  3. Bucket 0: (empty)
  4. Bucket 1: bat
  5. Bucket 2: cat
  6. Bucket 3: ant
  7. Bucket 4: dog
Colliding words share a bucket list; a lookup computes h(word), then scans only that bucket.
P7

Phone book

Entries: sam 99912222, tom 11122222, harry 12299933. Queries: sam, edward, harry. Show the output and the data structure you use.

Show solution
  1. Use a map from name (string) to number; build it from the 3 entries.
  2. Query sam: find succeeds → sam=99912222.
  3. Query edward: find returns end() → Not found.
  4. Query harry: harry=12299933.
Output: sam=99912222 / Not found / harry=12299933. Using unordered_map each lookup is O(1) on average, with map it is O(log n).
P8

Weather data queries

Data: Delhi 9-11 = 24, Delhi 10-11 = 26, Chennai 9-11 = 31, 10-11 = 33, 11-11 = 30, Mumbai 9-11 = 29, 10-11 = 30 (year 2018). Answer: (a) temperature in Delhi on 9-11-2018, (b) maximum temperature in Chennai, (c) number of entries, (d) delete Mumbai 9-11-2018, (e) delete all of Mumbai.

Show solution
  1. Data structure: map keyed by (city, date) with the temperature as the value (all keys are unique).
  2. (a) Look up (Delhi, 9-11-2018) → 24.
  3. (b) Scan Chennai entries 31, 33, 30 → maximum 33.
  4. (c) size() = 7.
  5. (d) erase((Mumbai, 9-11-2018)) → size 6.
  6. (e) Remove the remaining Mumbai entry → size 5.
(a) 24, (b) 33, (c) 7, (d) 6 entries left, (e) 4 entries left.
P9

Choose the structure

Pick set, map or dictionary (multimap) for: (a) remove repeated roll numbers from a list, (b) roll number → name, (c) word → all its meanings, (d) store the connected groups of friends.

Show solution
  1. (a) Set: duplicates are dropped automatically.
  2. (b) Map: one name per unique roll number.
  3. (c) Dictionary (multimap): one word, several meanings (duplicate keys).
  4. (d) Disjoint sets with union-find: union adds a friendship, find tells whether two people are in the same group.
(a) set, (b) map, (c) dictionary / multimap, (d) union-find on disjoint sets.
