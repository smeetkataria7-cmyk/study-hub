16

Data quality & missing data

Clean the data before you scale or bin it.
16.1

Data quality problems

  • Noise and outliers — random error or extreme values.
  • Missing values — attribute not recorded.
  • Duplicate data — the same entity listed twice.
  • Inconsistent or wrong data — conflicting units, impossible values.
16.2

Handling missing values

  • Ignore the tuple (poor when many values are missing).
  • Fill in manually, or with a global constant such as "unknown".
  • Fill with the attribute mean or median, or the mean of the same class.
  • Predict the value by regression or interpolation.
16.3

Linear regression (least squares)

y = a + bxb = n Σ xy − Σ x Σ yn Σ x2 − (Σ x)2,   a = ȳ − b x̄

Fit y on x from complete rows, then predict the missing y. Multiple regression: y = b0 + b1 x1 + b2 x2 + … by least squares.

16.4

Linear interpolation

y = y1 + (x − x1)(y2 − y1)x2 − x1

Straight line between the two known points on either side of the gap.

16.5

Lagrange interpolation

P(x) = Σi yi Πj ≠ i x − xjxi − xj

The unique polynomial of degree n − 1 through n points. Evaluate P at the missing x.

Normalization

Put attributes on a comparable scale.
17.1

Min–max normalization

v′ = v − minAmaxA − minA (newmax − newmin) + newmin

Linearly maps [minA, maxA] onto a new range, usually [0, 1]. Preserves the shape of the distribution but is distorted by outliers.

17.2

Z-score normalization

v′ = v − μAσA

Result has mean 0 and standard deviation 1. Good when the true min and max are unknown or outliers exist. Variant: divide by the mean absolute deviation sA = Σ |v − μA| / n.

17.3

Decimal scaling

v′ = v10j

j is the smallest integer for which max |v′| < 1.

18

Discretization & binning

Turn a continuous attribute into a few intervals.
18.1

Equal-width binning

w = max − mink

Bin edges are min, min + w, min + 2w, …, max. Simple, but outliers can leave most bins empty.

18.2

Equal-depth (equal-frequency) binning

values per bin ≈ nk

Sort, then cut into k bins holding about the same number of values. Handles skewed data better.

18.3

Smoothing by bins

  • Bin means — replace every value by the mean of its bin.
  • Bin medians — replace by the bin median.
  • Bin boundaries — replace each value by the closer of the bin's minimum or maximum.
18.4

Histogram discretization

Partition the range into buckets (equal width or equal frequency) and keep only each bucket's range and count. Lossy, but compact.

19

Decision-tree measures

Which attribute splits the data best?
19.1

Entropy (information)

Info(D) = −Σ pi log2 piInfoA(D) = Σ |Dj||D| Info(Dj)

Entropy measures impurity of the class labels: 0 when all tuples are in one class, 1 for a 50/50 two-class split. InfoA(D) is the weighted entropy after splitting on attribute A.

19.2

Information gain (ID3)

Gain(A) = Info(D) − InfoA(D)

Choose the attribute with the highest gain as the split. Biased towards attributes with many values.

19.3

Gain ratio (C4.5)

SplitInfoA(D) = −Σ |Dj||D| log2 |Dj||D|GainRatio(A) = Gain(A)SplitInfoA(D)

Normalises gain to remove the bias towards many-valued attributes.

19.4

Gini index (CART)

Gini(D) = 1 − Σ pi2GiniA(D) = Σ |Dj||D| Gini(Dj)ΔGini = Gini(D) − GiniA(D)

Impurity from 0 (pure) up to 1 − 1/k. Pick the split with the largest reduction (CART uses binary splits).

20

Clustering, attribute selection & sampling

Reduce data without losing its structure.
20.1

K-means clustering

ci = (Σ xn,   Σ yn)SSE = Σclusters Σx ∈ Ci dist(x, ci)2
  • Pick k initial centroids.
  • Assign every point to the nearest centroid (Euclidean).
  • Recompute each centroid as the mean of its points.
  • Repeat until the assignment stops changing.
20.2

Attribute subset selection

n attributes have 2ⁿ subsets, so heuristics are used:

  • Stepwise forward selection — start empty, add the best attribute each step.
  • Backward elimination — start with all, drop the worst each step.
  • Combination of the two.
  • Decision-tree induction — keep the attributes that appear in the tree.
20.3

Sampling

nh = n NhN
  • SRSWOR — simple random sample without replacement; SRSWR — with replacement.
  • Cluster sampling — pick whole clusters at random.
  • Stratified sampling — sample inside each stratum; proportional allocation uses the formula above.
