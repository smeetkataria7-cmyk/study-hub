12

Numeric data

How far apart are two objects described by numbers?
12.1

What makes a distance a metric

Similarity and dissimilarity are linked: for d ∈ [0, 1], s = 1 − d; otherwise s = 1/(1 + d) is common.

  • d(x, y) ≥ 0, and d = 0 only when x = y (positivity).
  • d(x, y) = d(y, x) (symmetry).
  • d(x, z) ≤ d(x, y) + d(y, z) (triangle inequality).
12.2

Minkowski distance (order p)

d(x, y) = ( Σ |xi − yi|p )1/p

The general form. The three common distances below are special cases; p ≥ 1 keeps it a metric.

12.3

Manhattan distance (p = 1, L₁)

d = Σ |xi − yi|

City-block distance: total of the absolute differences along each axis.

12.4

Euclidean distance (p = 2, L₂)

d = Σ (xi − yi)2

Straight-line distance. Sensitive to scale, so normalise attributes first (module 4).

12.5

Supremum distance (p → ∞, Chebyshev)

d = maxi |xi − yi|

The largest difference along any single attribute.

12.6

Mahalanobis distance

d(x, y) = (x − y)T S−1 (x − y)2-D  S = [ σx2   cov ; cov   σy2 ],   S−1 = 1det S [ σy2   −cov ; −cov   σx2 ]

S is the covariance matrix. It scales by variance and removes correlation between attributes. For a point against a distribution, use x − μ. If S is the identity matrix it reduces to Euclidean distance.

12.7

Bhattacharyya distance

BC(p, q) = Σ pi qiDB = −ln BC(p, q)two normals  DB = 14 (μp − μq)2σp2 + σq2 + 12 ln σp2 + σq22σpσq

Measures overlap between two probability distributions. 0 ≤ BC ≤ 1; no overlap gives BC = 0, identical distributions give BC = 1 and DB = 0.

12.8

Bregman divergence

Dφ(x, y) = φ(x) − φ(y) − ⟨∇φ(y), x − y⟩
  • φ strictly convex and differentiable: Dφ is the gap between φ and its tangent at y.
  • φ = ‖x‖² gives squared Euclidean distance.
  • φ = Σ p log p gives KL divergence, Σ pj log(pj / qj).
  • Not symmetric and does not satisfy the triangle inequality, so it is a divergence, not a metric.

13

Binary data

Match counts on 0/1 attributes, symmetric or asymmetric.
13.1

Contingency table of two binary objects

j = 1j = 0
i = 1q (both 1)r
i = 0st (both 0)

Tan's notation: M11 = q, M10 = r, M01 = s, M00 = t. Always q + r + s + t = number of attributes.

13.2

Symmetric binary — simple matching

d = r + sq + r + s + tSMC = q + tq + r + s + t = 1 − d

Both states carry equal weight (e.g. gender), so a 0-0 match is as informative as a 1-1 match.

13.3

Asymmetric binary — Jaccard

d = r + sq + r + sJ = qq + r + s = 1 − d

One state is rare and important (e.g. a positive test), so 0-0 matches are ignored. For sets, J = |A ∩ B| / |A ∪ B|.

13.4

Hamming distance

H = r + s

The number of positions at which two equal-length bit strings or words differ.

14

Textual data

Strings and documents: edit, overlap, angle and probability.
14.1

Edit (Levenshtein) distance

D(i, 0) = i,   D(0, j) = jD(i, j) = min{ D(i − 1, j) + 1,   D(i, j − 1) + 1,   D(i − 1, j − 1) + [ai ≠ bj] }

Minimum number of insertions, deletions and substitutions (each cost 1) to turn string 1 into string 2. Fill an (m + 1) × (n + 1) table; the answer is D(m, n). The bracket is 0 if the letters match, else 1.

14.2

Longest common subsequence (LCS)

L(i, 0) = L(0, j) = 0L(i, j) = { L(i − 1, j − 1) + 1   if   ai = bj ;   max( L(i − 1, j), L(i, j − 1) )   otherwise }

LCS distance = m + n − 2 · LCS (insert/delete only). Similarity = LCS / max(m, n).

14.3

Cosine similarity

cos(A, B) = A · B‖A‖ ‖B‖ = Σ ai biΣ ai2 Σ bi2cosine distance  1 − cos(A, B)

Angle between two term-frequency vectors; ignores document length. 1 = same direction, 0 = nothing in common.

14.4

Jaro & Jaro–Winkler similarity

simJ = 13( m|s1| + m|s2| + m − tm ) ,   0 if m = 0simW = simJ + ℓ · p (1 − simJ)
  • m = matching characters: same letter within ⌊max(|s1|, |s2|)/2⌋ − 1 positions.
  • t = transpositions = (matched letters in a different order) / 2.
  • ℓ = common prefix length (at most 4), p = 0.1. Jaro distance = 1 − sim.
14.5

n-gram distance

Dice = 2|G1 ∩ G2||G1| + |G2|,   Jaccard = |G1 ∩ G2||G1 ∪ G2|

Split each string into overlapping n-letter pieces: bigrams of "night" are ni, ig, gh, ht. Similarity from the shared pieces; distance = 1 − similarity.

14.6

n-gram language model

P(w1 … wn) = P(w1) P(w2 | w1) … P(wn | w1 … wn−1)unigram  P(wi) = C(wi)Nbigram  P(wi | wi−1) = C(wi−1 wi)C(wi−1)trigram  P(wn | wn−2, wn−1) = C(wn−2 wn−1 wn)C(wn−2 wn−1)

Maximum-likelihood estimates from counts C. A bigram sentence probability is the product of its bigram probabilities, with the markers <s> and </s> counted as words.

Mixed attribute types

One dissimilarity for a record that mixes numbers, labels and ranks.
15.1

Mixed-type dissimilarity

d(i, j) = Σf δij(f) dij(f)Σf δij(f)

Compute a 0–1 distance per attribute f, then take the weighted average. δ = 0 if a value is missing, or if the attribute is asymmetric binary and both values are 0; otherwise δ = 1.
