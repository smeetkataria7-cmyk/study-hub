1.1

Discrete vs continuous

Discrete attributes take a finite or countably infinite set of values: counts, zip codes, binary flags. Continuous attributes take real values: height, temperature, time.

Practically, continuous values are measured to finite precision and stored as floats.

1.2

Qualitative vs quantitative

  • Nominal + ordinal = qualitative (categorical).
  • Interval + ratio = quantitative (numeric).
  • Each type allows all the operations of the types above it in the table: ratio data supports everything, nominal data only equality.
1.3

Types of datasets

  • Record data — data matrix, document-term matrix, transaction (market-basket) data.
  • Graph-based data — WWW links, social networks, molecular structures.
  • Ordered data — sequences (DNA), time series (stock prices), spatial data (weather maps, satellite images).
1.4

General characteristics of datasets

  • Dimensionality — number of attributes; very high values cause the curse of dimensionality.
  • Sparsity — most values are zero (text, transactions).
  • Resolution — patterns depend on the scale of measurement.
  • Also: distribution, size, noise.
1.5

Data Science vs Data Analytics vs Data Engineering

Data Science predicts and builds models to find unknown patterns (Python, ML, statistics). Data Analytics answers specific business questions from existing data (SQL, Excel, BI dashboards). Data Engineering builds the pipelines and storage that collect and prepare the data (ETL, Spark, Hadoop, databases).

1.6

Classical analysis vs Exploratory Data Analysis (EDA)

classical  Problem → Data → Model → Analysis → ConclusionsEDA  Problem → Data → Analysis → Model → Conclusions

Classical analysis assumes a model first and relies on quantitative tests. EDA looks at the data first, is mostly graphical, and lets the data suggest the model.

1.7

Applications of data science

Medical and healthcare (diagnosis, drug discovery, image analysis), agriculture (crop-yield prediction, soil and weather analysis), disaster management (early warning, damage assessment), plus finance, e-commerce and transport. No formulas in this unit.
