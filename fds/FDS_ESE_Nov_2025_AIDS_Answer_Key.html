How they are interrelated: they form a pipeline in a data-driven project.

  1. Data engineers collect raw data from sources, clean it and load it into a warehouse.
  2. Data analysts query that data to describe what happened (for example, a sales drop in one region).
  3. Data scientists use the same data to build models that predict or prescribe (for example, forecast next month's sales).
  4. The model's results go back into the engineered pipeline and into analysts' dashboards. Each role depends on the others: no clean data means no analysis, and no analysis means no direction for modelling.

Example: in an e-commerce recommendation project, engineers stream click data, analysts find which categories sell, and scientists train the recommender.

Q1 (ii) Role of Data Science in medical and healthcare applications

  • Diagnosis from medical images: deep learning models detect tumours, fractures and diabetic retinopathy in X-rays, MRI and retina scans.
  • Disease prediction and risk scoring: models predict diabetes, heart disease or hospital readmission from patient records.
  • Drug discovery: ML screens millions of molecules and predicts protein structures, shortening development time.
  • Personalised medicine: treatment chosen from a patient's genetics and history.
  • Hospital operations: forecasting bed demand, staff scheduling, reducing waiting times.
  • Wearables and remote monitoring: real-time analysis of heart rate, ECG and glucose data.
  • Epidemic tracking: predicting outbreak spread (as done during COVID-19).

Case study 1, Google DeepMind and diabetic retinopathy: a deep learning model trained on retina photographs detects diabetic retinopathy with accuracy comparable to eye specialists, used in screening programmes in India and Thailand where specialists are scarce.

Case study 2, DeepMind AlphaFold: predicts the 3-D structure of proteins from their amino-acid sequence, which used to take years in the lab. It speeds up drug design and understanding of diseases.

Other valid examples: IBM Watson for oncology, COVID-19 spread forecasting, Apple Watch atrial fibrillation alerts.

Q1 (iii) Graph-based data, with an example from social network analysis

Graph-based data represents entities as nodes (vertices) and the relationships between them as edges (links). G = (V, E). Edges can be directed (Twitter follows) or undirected (Facebook friendship), and weighted (number of messages exchanged) or unweighted. The relationships themselves are the important information, which a flat table does not capture well.

Other examples: the World Wide Web (pages and hyperlinks), road networks, molecular structures, citation networks.

Social network example: users A, B, C, D, E with friendships A–B, A–C, B–C, C–D, D–E.

  A ─── B
   \   /
    \ /
     C ─── D ─── E

Analysis we can do on this graph:

  • Degree centrality: C has the most connections (3), so C is the most influential user.
  • Betweenness: C and D lie on the path between the A–B–C group and E, so they act as bridges.
  • Community detection: {A, B, C} form a tightly connected group (a triangle).
  • Friend recommendation: A and D share friend C, so suggest "People you may know: D" to A.

Q2 (i) Corrected mean and standard deviation

Given n = 150, x̄ = 40, σ = 15. Wrong values 34 and 63; correct values 43 and 36.

Step 1: Corrected mean

Σx (wrong) = n·x̄ = 150 × 40 = 6000
Σx (correct) = 6000 − (34 + 63) + (43 + 36) = 6000 − 97 + 79 = 5982
Corrected mean = 5982 / 150 = 39.88

Step 2: Corrected Σx²

σ² = Σx²/n − x̄² ⇒ Σx² = n(σ² + x̄²)
Σx² (wrong) = 150 × (225 + 1600) = 150 × 1825 = 273750
Σx² (correct) = 273750 − (34² + 63²) + (43² + 36²)
= 273750 − (1156 + 3969) + (1849 + 1296) = 273750 − 5125 + 3145 = 271770

Step 3: Corrected SD

σ² = 271770/150 − 39.88² = 1811.8 − 1590.4144 = 221.3856
σ = √221.3856 = 14.88
Corrected mean = 39.88, corrected standard deviation ≈ 14.88

Q2 (ii) Moments about the mean and about zero

Moments about A = 5: μ′₁ = −4, μ′₂ = 22, μ′₃ = −117, μ′₄ = 560.

Mean: x̄ = A + μ′₁ = 5 + (−4) = 1

(i) Moments about the mean

μ₁ = 0
μ₂ = μ′₂ − μ′₁² = 22 − 16 = 6
μ₃ = μ′₃ − 3μ′₂μ′₁ + 2μ′₁³ = −117 − 3(22)(−4) + 2(−64) = −117 + 264 − 128 = 19
μ₄ = μ′₄ − 4μ′₃μ′₁ + 6μ′₂μ′₁² − 3μ′₁⁴
   = 560 − 4(−117)(−4) + 6(22)(16) − 3(256) = 560 − 1872 + 2112 − 768 = 32

(ii) Moments about zero (x = d + 5, where d is the deviation from 5)

ν₁ = μ′₁ + 5 = −4 + 5 = 1
ν₂ = μ′₂ + 2(5)μ′₁ + 5² = 22 − 40 + 25 = 7
ν₃ = μ′₃ + 3(5)μ′₂ + 3(5²)μ′₁ + 5³ = −117 + 330 − 300 + 125 = 38
ν₄ = μ′₄ + 4(5)μ′₃ + 6(5²)μ′₂ + 4(5³)μ′₁ + 5⁴
   = 560 − 2340 + 3300 − 2000 + 625 = 145

Check: μ₂ = ν₂ − ν₁² = 7 − 1 = 6 ✓

About the mean: 0, 6, 19, 32  |  About zero: 1, 7, 38, 145

Q5: Types of frequency distribution (10 marks)

A frequency distribution is a table that shows how often each value, or range of values, occurs in a dataset. It summarises raw data so patterns become visible.

Example raw data, marks of 20 students: 12, 15, 11, 18, 15, 22, 25, 15, 18, 21, 28, 12, 30, 22, 15, 26, 18, 24, 29, 19.

1. Simple (ungrouped) frequency distribution

Each distinct value is listed with its frequency. Used for discrete data with few distinct values. Example, goals scored in 15 matches:

Goals01234
Frequency25431

2. Grouped frequency distribution

Values are grouped into class intervals. Used for continuous data or many distinct values. Key terms: class limits, class width, class mark (mid-point). Using the marks above:

Marks10–1515–2020–2525–3030–35
Frequency38441

(Exclusive classes: 15 goes into 15–20.)

3. Cumulative frequency distribution

Running total of frequencies. Less-than type adds from the top; more-than type adds from the bottom. Used for median, quartiles and ogives.
