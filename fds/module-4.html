4

Preprocessing

Clean, scale, bin and reduce the data before modelling.
4.1

Why preprocess data?

Real data are incomplete, noisy and inconsistent, and poor input gives poor models ("garbage in, garbage out"). Preprocessing usually takes most of a project's time.

  • Quality dimensions: accuracy, completeness, consistency, timeliness, believability, interpretability.
  • Major tasks: data cleaning, integration, reduction, transformation and discretization.
4.2

Data quality problems

  • Noise and outliers: random error, or values far from the rest.
  • Missing values: not recorded, not applicable or lost.
  • Duplicate data: the same entity repeated (often after merging sources).
  • Inconsistent or wrong data: conflicting codes or units, impossible values.
4.3

Handling missing values

TypeMeaning
MCARMissing completely at random
MARMissing depends on other recorded attributes
MNARMissing depends on the missing value itself
  • Ignore the tuple (loses data) or fill manually (slow).
  • Fill with a global constant, the attribute mean / median, or the class-wise mean.
  • Predict the value by regression, interpolation or a decision tree (usually best).
4.4

Handling noise

  • Binning: sort, split into bins and smooth by bin means, medians or boundaries.
  • Regression: fit a function and replace values by fitted ones.
  • Clustering: values outside all clusters are outliers.
  • Combined computer and human inspection of suspicious values.
4.5

Regression and interpolation

  • Linear regression fits y = a + bx by least squares; multiple regression uses several predictors. Used to predict missing values and smooth noise.
  • Interpolation estimates a value between known points: linear (straight line between two neighbours) or Lagrange polynomial through several points.
  • Regression gives a model that does not pass through every point; interpolation passes through all known points.
4.6

Data integration

Combining data from several sources raises entity identification (same entity, different names), redundant attributes (detect with correlation or χ² tests), conflicts in values and units, and duplicates.

4.7

Normalization methods

Normalisation puts attributes on comparable scales so that distance-based methods (k-means, kNN) and gradient-based models are not dominated by large-valued attributes.

4.8

Discretization

Replaces a continuous attribute by intervals or concept labels, reducing data size and enabling methods that need categorical data.

  • Unsupervised (ignores class): equal-width binning, equal-depth binning, histogram analysis, clustering.
  • Supervised (uses class labels): decision-tree or entropy-based splitting, ChiMerge.
  • Top-down (split) vs bottom-up (merge) strategies.
  • Equal-width is simple but skewed by outliers; equal-depth gives balanced bins.
4.9

Clustering (k-means)

  • Partition data into k groups so objects in a cluster are similar and clusters differ.
  • Steps: choose k centroids → assign every point to the nearest centroid → recompute each centroid as the mean → repeat until assignments stop changing.
  • Strengths: simple and fast. Limits: must fix k, sensitive to initial centroids and outliers, prefers spherical clusters; hierarchical clustering needs no k.
4.10

Decision trees

  • A flowchart-like tree: internal node = test on an attribute, branch = outcome, leaf = class.
  • Build top-down by choosing the attribute that best splits the data: information gain (ID3), gain ratio (C4.5), Gini index (CART).
  • Overfitting (tree too deep) is controlled by pruning.
  • Advantages: easy to interpret, handles mixed data. Also used for attribute selection and discretization.
4.11

Data reduction: attribute subset selection and sampling

  • Attribute subset selection removes irrelevant or redundant attributes: stepwise forward selection, backward elimination, their combination, and decision-tree induction. n attributes give 2n subsets, so heuristics are used.
  • Dimensionality reduction (PCA, wavelets) and numerosity reduction (sampling, histograms, clustering) shrink the data.
  • Sampling: simple random with / without replacement, cluster, stratified (keeps each group's proportion; good for skewed classes).
