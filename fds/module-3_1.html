Similarity & dissimilarity

How alike are two objects?
3.1

Similarity and dissimilarity

Similarity is a number saying how alike two objects are (high = alike, often in [0, 1]); dissimilarity (distance) says how different they are (low = alike). Together they are called proximity measures. They are the foundation of clustering, nearest-neighbour classification, recommenders and outlier detection.

Conversion: s = 1 − d when d ∈ [0, 1], or s = 1/(1 + d).

3.2

Metric properties

  • Positivity: d(x, y) ≥ 0, and d(x, y) = 0 only if x = y.
  • Symmetry: d(x, y) = d(y, x).
  • Triangle inequality: d(x, z) ≤ d(x, y) + d(y, z).
  • A measure with all three is a metric. Cosine similarity and the Bregman divergence are not metrics.
3.3

Choosing a distance for numeric data

DistanceIdeaUse when
EuclideanStraight-line distanceAttributes on the same scale, continuous data, spherical clusters
ManhattanSum of axis differences (city blocks)High dimensions, grid-like movement, less sensitive to large single differences
Supremum (Chebyshev)Largest single differenceOnly the worst attribute matters
MinkowskiGeneral order pTo tune between the above
MahalanobisDistance scaled by the covariance matrixCorrelated attributes of different scales; point to distribution
CosineAngle between vectorsDirection matters, not length (documents)

Scale attributes first (normalisation, module 4): otherwise the attribute with the largest range dominates Euclidean distance.

3.4

Distances between distributions

  • Bhattacharyya distance measures the overlap of two probability distributions (0 for identical ones); used in classification and image / speech work.
  • Bregman divergence generalises squared Euclidean distance and KL divergence through a convex function; asymmetric and not a metric.
3.5

Binary attributes

  • Compare two objects by counts of matches: q (1,1), r (1,0), s (0,1), t (0,0).
  • Symmetric attributes (both values matter): use the simple matching coefficient, which counts 0-0 matches.
  • Asymmetric attributes (presence is rare and important): use Jaccard, which ignores 0-0 matches.
  • Hamming distance counts the positions that differ.
3.6

Measures for textual data

MeasureIdeaTypical use
Edit (Levenshtein)Fewest insertions, deletions, substitutionsSpell checking, DNA, record matching
CosineAngle between term-frequency vectorsDocument similarity, search engines
Jaro / Jaro–WinklerMatching characters and transpositions; prefix bonusMatching names and short strings
n-gramOverlap of n-letter piecesFuzzy matching, plagiarism
Longest common subsequenceLongest in-order shared sequenceDiff tools, bioinformatics

Documents are turned into vectors with a bag of words (counts or TF-IDF), ignoring word order; an n-gram language model predicts a word from the previous n − 1 words.

3.7

Dissimilarity for mixed attribute types

A record can mix numeric, nominal, binary and ordinal attributes. Compute a 0–1 dissimilarity for each attribute (numeric: range-scaled difference; nominal: 0 or 1; ordinal: ranks mapped to [0, 1]) and take the weighted average, skipping missing values and asymmetric 0-0 pairs.

3.8

Applications

  • Clustering and nearest-neighbour search, recommendation systems, plagiarism detection.
  • Spelling correction, deduplication and record linkage, image and speech retrieval, anomaly detection.
