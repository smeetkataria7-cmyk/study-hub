1. Formula sheet

Interpolation (estimating inside the known range)

Linear: y = y0 + (y1 − y0)/(x1 − x0) · (x − x0) valid for x0 ≤ x ≤ x1. Outside that range it is extrapolation.
Same line as y = A + Bx:   B = (y1 − y0)/(x1 − x0),   A = (y0x1 − y1x0)/(x1 − x0)
Lagrange polynomial: P(x) = Σ yi Li(x),   Li(x) = Πj≠i (x − xj)/(xi − xj)Passes exactly through all N points; the polynomial is unique.

Regression (a model fitted to all the data)

Simple linear: y = a + bx
b = (nΣxy − ΣxΣy) / (nΣx² − (Σx)²)
a = (Σy − bΣx)/n = ȳ − b·x̄Least squares: a and b minimise the error between the data and the line.
Multiple (two predictors): ŷ = b0 + b1x1 + b2x2
b1 = [(Σx2²)(Σx1y) − (Σx1x2)(Σx2y)] / [(Σx1²)(Σx2²) − (Σx1x2)²]
b2 = [(Σx1²)(Σx2y) − (Σx1x2)(Σx1y)] / [same denominator]
b0 = ȳ − b1x̄1 − b2x̄2Here the sums are corrected sums, e.g. Σx1² = ΣX1² − (ΣX1)²/n and Σx1y = ΣX1Y − (ΣX1)(ΣY)/n.

Normalization

Min-max: v′ = (v − min)/(max − min) · (new_max − new_min) + new_min
Z-score: v′ = (v − μ)/σ   (μ = mean, σ = standard deviation)
Decimal scaling: v′ = v / 10j,   j = smallest integer such that max|v′| < 1

Discretization and binning

Equal-width: W = (B − A)/N   (A = lowest, B = highest value, N = number of intervals)
Equal-depth (equal-frequency): each of N bins holds about the same number of values
Smoothing: replace each value in a bin by the bin mean, median or the nearest bin boundary

2. Theory questions and model answers

T1 What is interpolation? Name its types. Lecture 13

Interpolation is a method of estimating unknown values that fall within the range of known data points. It assumes that the trend between the known points continues in the same manner. It is a family of methods from Numerical Analysis, used to fill gaps between observed points and give a complete, continuous representation of a function. Example: temperature measured at fixed times; interpolation estimates the temperature at a time in between.

Types: linear, polynomial (e.g. Lagrange) and spline.

T2 Explain linear interpolation with the formula and an example.

Linear interpolation estimates a value between two known points by joining them with a straight line, assuming a linear relationship between them. For points (x0, y0) and (x1, y1) the line is y = A + Bx with B = (y1 − y0)/(x1 − x0) and A = (y0x1 − y1x0)/(x1 − x0). It suits limited data and is used in mathematics, physics, finance and computer science.

Example: population 2.0 million in 2000 and 2.5 million in 2010; the line gives B = 0.05 and the 2005 estimate 2.25 million.

T3 Explain polynomial interpolation and splines.
  • Polynomial interpolation: for N points a polynomial can always be found that passes through all of them, and it is unique. Polynomials are easy to evaluate, differentiate and integrate. Example: Lagrange's interpolation.
  • Splines: special functions defined piecewise using low-degree polynomials. Popular for easy evaluation, accuracy and the ability to fit complex shapes. They are smoother and more accurate than a single Lagrange polynomial.
T4 What is regression? Explain linear and multiple linear regression.

Regression is a statistical method for finding the relationship between a dependent variable (response) and one or more independent variables (predictors or features). The aim is to find the best-fitting line or curve so that the response can be predicted, and it can also predict outside the known range (extrapolation).

  • Linear regression: the data are modelled to fit a straight line, y = a + bx, where b is the slope and a the intercept. The coefficients are estimated from n observed pairs by the method of least squares, which minimises the error between the data and the line. Because real data scatter, the full model is y = a + bx + ε, where ε is a random error.
  • Multiple linear regression: an extension that models the response as a linear function of two or more predictors, y = b0 + b1x1 + b2x2 + …

Uses: trends and sales estimates, the effect of price changes, risk assessment in financial services.

T6 How can missing data be handled? Explain predicting missing values by regression. borderline: data cleaning

Missing data are questions without answers or variables without observations; even a small percentage can lead to wrong conclusions. Six ways to fill them:

  1. Ignore the data row (tuple) completely, usually when the class label is missing. Not effective if the percentage of missing values per attribute varies a lot.
  2. Fill the missing value manually (tedious, often infeasible).
  3. Use a global constant such as "unknown".
  4. Use the attribute mean.
  5. Use the attribute mean of all samples belonging to the same class (smarter).
  6. Use the most probable value, predicted by an inference method such as regression, a Bayesian formula or a decision tree.

Regression method: fit a regression model to the observed values, then use the fitted equation to predict the missing value (for a variable with missing values, a model is fitted and used to impute them; for several variables the process is repeated in turn). Interpolation method: if the missing value lies between two known points, estimate it on the straight line joining them.

T7 What is data normalization? Explain min-max, z-score and decimal scaling.

Normalization is a data transformation that scales the values of an attribute to fall within a smaller, specified range, so attributes with large ranges do not dominate those with small ranges.

  • Min-max: a linear mapping of [min, max] to [new_min, new_max]. v′ = (v − min)/(max − min) × (new_max − new_min) + new_min. Example: income range 12,000–98,000 mapped to [0, 1]; 73,000 becomes (73,000 − 12,000)/86,000 = 0.709. It keeps the original relationships but is sensitive to outliers.
  • Z-score: v′ = (v − μ)/σ. With μ = 54,000 and σ = 16,000, the value 73,600 becomes 1.225. Useful when the minimum and maximum are unknown or outliers dominate. The result has mean 0 and SD 1.
  • Decimal scaling: move the decimal point: v′ = v/10j, where j is the smallest integer with max|v′| < 1. For values from −986 to 917, j = 3, so −986 becomes −0.986.
T8 What is discretization? Explain the methods.

Discretization divides the range of a continuous attribute into intervals; interval labels then replace the actual values. It reduces data size and prepares data for further analysis such as classification. It can be supervised (uses class labels) or unsupervised, and top-down (split) or bottom-up (merge), and can be applied recursively. Typical methods:

MethodKind
BinningUnsupervised, top-down split
Histogram analysisUnsupervised, top-down split

Decision-tree analysis (uses entropy to pick split points)Supervised, top-down split
Correlation analysis (ChiMerge, chi-square based)Supervised, bottom-up merge
T9 Explain binning: equal-width and equal-depth partitioning, and smoothing by bin means and boundaries.
  • Equal-width (distance): divides the range into N intervals of equal size, W = (B − A)/N. Simple, but outliers may dominate and skewed data is handled poorly.
  • Equal-depth (frequency): each of the N intervals holds about the same number of samples. Gives good scaling, but categorical attributes are tricky.
  • Smoothing (first sort the data and partition into bins): replace each value by the bin mean, the bin median, or the closest bin boundary.

Example: sorted prices 4, 8, 9, 15, 21, 21, 24, 25, 26, 28, 29, 34 in 3 equal-depth bins: (4, 8, 9, 15), (21, 21, 24, 25), (26, 28, 29, 34). By means: 9, 23, 29. By boundaries: (4, 4, 4, 15), (21, 21, 25, 25), (26, 26, 26, 34).

T10 What is a concept hierarchy? borderline

A concept hierarchy organises attribute values into levels, replacing low-level values (such as age in numbers) with higher-level concepts (youth, adult, senior). For numeric data it is built by discretization; for nominal data by ordering attributes (street < city < state < country) or grouping values ({Urbana, Champaign, Chicago} < Illinois). It supports drilling and rolling in data warehouses.

5. Step-by-step solutions

P1: Linear interpolation

  1. Points (x0, y0) = (2, 20) and (x1, y1) = (4, 26).
  2. Slope = (26 − 20)/(4 − 2) = 3 °C per hour.
  3. At x = 3: y = 20 + 3(3 − 2) = 23 °C. At x = 2.5: y = 20 + 3(0.5) = 21.5 °C.

P2: Population

  1. B = (2.5 − 2.0)/(2010 − 2000) = 0.05.
  2. A = (y0x1 − y1x0)/(x1 − x0) = (2.0 × 2010 − 2.5 × 2000)/10 = (4020 − 5000)/10 = −98.
  3. 2005: y = −98 + 0.05 × 2005 = −98 + 100.25 = 2.25 million.
  4. 2022: y = −98 + 0.05 × 2022 = −98 + 101.1 = 3.1 million.
  5. 2022 is beyond the last known year (2010), so it is not interpolation. Using the line outside the data range is extrapolation, which is less reliable because the trend may not continue.

P3: Lagrange

  1. L0(3) = (3 − 2)(3 − 4)/((1 − 2)(1 − 4)) = (1)(−1)/3 = −1/3.
  2. L1(3) = (3 − 1)(3 − 4)/((2 − 1)(2 − 4)) = (2)(−1)/(−2) = 1.
  3. L2(3) = (3 − 1)(3 − 2)/((4 − 1)(4 − 2)) = 2/6 = 1/3.
  4. P(3) = 1(−1/3) + 4(1) + 16(1/3) = −1/3 + 4 + 16/3 = 9 (the points lie on y = x²).

P5: Missing value at x = 64

  1. Regression: y = −7.9635 + 0.18784 × 64 = −7.9635 + 12.022 = 4.06.
  2. Interpolation: the neighbours are (63, 4.0) and (65, 4.1). At x = 64, the midpoint: y = 4.0 + (0.1/2)(1) = 4.05.
  3. The two estimates are close. Interpolation uses only the two nearest points; regression uses all points and smooths them. The point (64, ?) lies inside the data range, so both are valid.

P6: Regression line

  1. Σx = 15, Σy = 20, Σxy = 2 + 8 + 15 + 16 + 25 = 66, Σx² = 1 + 4 + 9 + 16 + 25 = 55, n = 5.
  2. b = (5 × 66 − 15 × 20)/(5 × 55 − 15²) = (330 − 300)/(275 − 225) = 30/50 = 0.6.
  3. a = (20 − 0.6 × 15)/5 = 11/5 = 2.2.
  4. y = 2.2 + 0.6x. At x = 6: y = 2.2 + 3.6 = 5.8. (x = 6 is outside 1–5, so this is extrapolation.)

P7: Slope and intercept

  1. b = (nΣxy − ΣxΣy)/(nΣx² − (Σx)²) = (4 × 230 − 50 × 44)/(4 × 150 − 50²) = (920 − 2200)/(600 − 2500) = −1280/−1900 = 0.674.
  2. a = (Σy − bΣx)/n = (44 − 0.674 × 50)/4 = (44 − 33.68)/4 = 2.58. (The other formula gives the same: (44 × 150 − 50 × 230)/(−1900) = −4900/−1900 = 2.579.)
  3. Line: y = 2.58 + 0.674x.

P8: Multiple regression prediction

  1. (76, 13): ŷ = −6.867 + 3.148 × 76 − 1.656 × 13 = −6.867 + 239.248 − 21.528 = 210.85.
  2. (70, 20): ŷ = −6.867 + 3.148 × 70 − 1.656 × 20 = −6.867 + 220.36 − 33.12 = 180.37.

P9: Min-max

  1. (a) [0, 1]: (73,000 − 12,000)/(98,000 − 12,000) = 61,000/86,000 = 0.709.
  2. [−1, 1]: 0.709 × (1 − (−1)) + (−1) = 1.419 − 1 = 0.419.
  3. (b) min = 200, max = 1000, range 800: (200 − 200)/800 = 0; 100/800 = 0.125; 200/800 = 0.25; 400/800 = 0.5; 800/800 = 1. Result 0, 0.125, 0.25, 0.5, 1.

P10: Z-score

  1. (a) Mean = 30. Deviations −20, −10, 0, 10, 20; squares 400, 100, 0, 100, 400; sum 1000; population SD = √(1000/5) = √200 = 14.142.
  2. z = −20/14.142 = −1.414; −10/14.142 = −0.707; 0; 0.707; 1.414. (With the sample SD 15.81 the values would be −1.265, −0.632, 0, 0.632, 1.265.)
  3. (b) z = (73,600 − 54,000)/16,000 = 19,600/16,000 = 1.225.

P11: Decimal scaling

  1. The largest absolute value is 986.
  2. We need 986/10j < 1; j = 2 gives 9.86 (too big), j = 3 gives 0.986 (valid). So j = 3.
  3. −986 → −0.986; 917 → 0.917.

P12: Binning

  1. (a) 12 values, 3 bins, so 4 values each: Bin 1 = (4, 8, 9, 15); Bin 2 = (21, 21, 24, 25); Bin 3 = (26, 28, 29, 34).
  2. Bin means: (4 + 8 + 9 + 15)/4 = 9; (21 + 21 + 24 + 25)/4 = 22.75 ≈ 23; (26 + 28 + 29 + 34)/4 = 29.25 ≈ 29. Smoothed: (9, 9, 9, 9), (23, 23, 23, 23), (29, 29, 29, 29).
  3. Bin boundaries: each value moves to the nearer of its bin's minimum and maximum. Bin 1: 4 → 4, 8 → 4 (closer to 4 than to 15), 9 → 4, 15 → 15. Bin 2: 21 → 21, 21 → 21, 24 → 25, 25 → 25. Bin 3: 26 → 26, 28 → 26, 29 → 26, 34 → 34.
  4. (b) W = (34 − 4)/3 = 10. Intervals [4, 14), [14, 24), [24, 34]. Counts 3, 3 and 6, so equal-width bins are uneven when the data is skewed.

P13: Mean imputation

  1. Known values: 10, 12, 14, 16; sum = 52; count = 4.
  2. Mean = 52/4 = 13, so the missing value is filled with 13.

6. Errors I found in the slides

  1. Lecture 13, "interpolation" of the 2022 population. 2000 and 2010 are the known points, so 2022 is outside the range. Strictly this is extrapolation.
  2. Lecture 13, regression version of the same example. The slide gets a slope of 0.025 and a prediction of 2.675 million. The numerator is 5 × 0.25 + (−5)(−0.25) = 2.5 and the denominator 50, so the slope is 0.05, the intercept −98 and the 2022 prediction 3.1 million, the same as the interpolation answer (a line through two points is the line through two points).
  3. Lecture 13, intercept line: "Y = −98 + 005 × 2022" is a typo for 0.05.
  4. Lecture 13, slope rounding: b = 13.9/74 = 0.1878, which the slide rounds to 0.19 and gets 4.822 for x = 68. With b = 0.188 you get 4.81.
  5. Lecture 13, multiple regression: the b2 line uses 1,152.5 where the earlier sum was 1,162.5. With 1,162.5 you get b2 = −1.656, the slide's answer, so 1,152.5 is a typo.
