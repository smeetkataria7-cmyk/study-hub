Fundamentals of data

What data is, how attributes behave and what data science does.
1.1

Data, attribute and object

Data are raw facts and figures collected by observation or measurement. A data object (record, sample, tuple, instance) is one entity described by a set of attributes (variable, feature, field, dimension). A dataset is a collection of data objects.

From data to value: data → information (organised, meaningful) → knowledge (patterns, rules) → decisions.

Each type adds a property to the one before it: nominal ⊂ ordinal ⊂ interval ⊂ ratio. Qualitative (categorical) = nominal + ordinal (+ binary); quantitative (numeric) = interval + ratio.

1.3

Discrete and continuous attributes

  • Discrete: finite or countably infinite values (counts, zip codes, binary flags); often integers.
  • Continuous: real values within an interval (height, temperature); measured to limited precision, represented as floats.
  • Asymmetric binary attributes are usually treated as discrete in similarity work.

1.5

General characteristics of datasets

  • Dimensionality — the number of attributes. Very high dimensionality causes the curse of dimensionality: data become sparse, distances lose meaning, and analysis gets costly (dimension reduction helps).
  • Sparsity — most values are zero or absent (text, transactions); store only non-zero entries.
  • Resolution — patterns depend on the scale: too fine hides patterns in noise, too coarse loses them.
  • Also: size, distribution (centre, spread, shape) and noise.
1.6

What is data science?

An interdisciplinary field that uses statistics, programming and domain knowledge to extract insight and build predictive models from data.

  • Life cycle: problem definition → data collection → data preparation (cleaning, integration, transformation) → exploration (EDA) → modelling → evaluation → communication and deployment.
  • Skills: mathematics and statistics, programming (Python, R, SQL), machine learning, visualisation, domain knowledge.

1.8

Types of analytics

  • Descriptive — what happened (summaries, charts).
  • Diagnostic — why it happened (drill-down, correlation).
  • Predictive — what will happen (regression, classification, forecasting).
  • Prescriptive — what to do about it (optimisation, recommendation).
1.9

Exploratory data analysis (EDA) vs classical analysis

BasisClassicalEDA
SequenceProblem → Data → Model → Analysis → ConclusionsProblem → Data → Analysis → Model → Conclusions
Starting pointAssumes a model firstLets the data suggest the model
MethodsMostly quantitative testsMostly graphical, with summary numbers
AssumptionsStrong (e.g. normality)Few, checked from the data

EDA goals: understand structure, spot outliers and anomalies, test assumptions, choose variables, and develop a parsimonious model. Tools: histogram, boxplot, scatter plot, Q-Q plot, summary statistics.

1.10

Applications of data science

  • Healthcare: disease diagnosis from images, drug discovery, patient-risk prediction.
  • Agriculture: crop-yield prediction, soil and weather analysis, pest detection.
  • Disaster management: early warning, damage assessment from satellite data, resource allocation.
  • Also finance (fraud detection, credit scoring), e-commerce (recommendation), transport (route and demand prediction).
  • Challenges: poor data quality, privacy and ethics, bias, scalability, interpretability.
